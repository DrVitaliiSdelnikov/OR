# Каталог прицелов

Пометка автора к В14: нужны разные прицелы и кратности. Логика — моя. Статус: план, каталог ещё не составлен.

- [ ] Составить каталог: фиксированный 10×, переменный 3–12×, 5–25×; сетки Ёлка / MIL-dot / MOA / Fine; первая и вторая фокальная плоскость (вторая — как усложнение: поправка по сетке верна только на одной кратности); цена клика 0,1 MIL / ¼ MOA; ход барабана и ZERO STOP
- [ ] Где открываются: по упражнениям курса, в свободной игре — плитка «Прицел»
- [ ] Свести с тем, что есть в коде (SCOPES: Ёлка / MOA / Dot / Fine, pxPerMil = 3,4 × кратность)
