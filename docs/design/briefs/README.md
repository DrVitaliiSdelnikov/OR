# Брифы для дизайнера

Задание на каждый экран для дизайнера (на этапе прототипа это Claude, В23). Бриф — готовое ТЗ на холст. Числа и формулы в брифах не повторяются: в них ссылки на [FORMULAS](../../logic/FORMULAS.md), цвета и размеры — на [TOKENS](../TOKENS.md). Если в брифе стоит число, это пример раскладки, а не правило.

## Общие требования ко всем холстам

- Артборд 390 × 844 pt, портрет. Поля 16, касание ≥ 44, текст ≥ 13 pt, контраст текста ≥ 4,5:1.
- Язык «прибор и бумага» (TOKENS). Чернила, графит и красный карандаш строго по смыслу: кто записал.
- Тексты на «ты», команды короткие. Без «пожалуйста», без эмодзи.
- Одна функция — одно место (правило README). Не рисовать вторую кнопку того же действия на соседнем экране.
- Числа на холсте — только из [эталонных наборов FORMULAS](../../logic/FORMULAS.md#эталонные-примеры-для-холстов-и-текстов) (А — базовый, Б — округление, В — подстановка, Г — условия, Д — упреждение, Е — жара). Один набор на артборд, подписать букву набора в углу артборда. Свои числа не придумывать.
- В первом релизе нет угла: никаких «D′ 272», «дистанция по углу», «+25°» (Б5).
- Показывать все состояния экрана (таблица «Состояния» в брифе), а не только «счастливый путь».
- Подписывать артборды номером брифа и состоянием: «01 · Секция стрелка · докрутка».

## Шаблон брифа

1. **Зачем экран** — одна фраза.
2. **Вход и выход** — откуда приходят, куда уходят.
3. **Состав сверху вниз** — блоки с примерной геометрией.
4. **Состояния** — таблица.
5. **Взаимодействие** — жесты, звук, вибрация.
6. **Тексты** — образцы строк.
7. **Важно / нельзя.**
8. **Источники** — решения из QUESTIONS и холсты-референсы.
