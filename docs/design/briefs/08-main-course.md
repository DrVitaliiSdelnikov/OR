# 08 · Главный экран и курс-тропа

**Зачем.** Вход в игру. Командное меню вместо вкладок приложения (В1) и путь по курсу.

Референс: [игровой слой](https://claude.ai/artifact/S5PTbWpgZRp3GPR9oJAmsd) — артборды «Главный экран» и «Допуски».

## Главный экран

| Блок | Содержание |
| --- | --- |
| Фон | живой: сетка прицела чуть качается, дымка ползёт по горам (В26) |
| Шапка | слева звание со знаком и «допуски 4 / 12» (В20, COURSE); справа шестерёнка настроек (12) |
| Название | «ОГНЕВОЙ РУБЕЖ» |
| Меню | 01 «Снайперская подготовка» · 02 «Свободная игра» · 03 «Учебник курсанта» · 04 «Журнал стрелка» — крупные плитки-кнопки с номерами |
| Низ | карточка «ПРОДОЛЖИТЬ» (В28): номер и название текущего упражнения, класс прошлой попытки или «новое» (допуски уже в шапке, в карточке их не повторяем); тап — брифинг (06). Курс пройден — «СВОБОДНАЯ ИГРА · последние условия». Первый запуск — «НАЧАТЬ · 00 ВИНТОВКА И ПРИЦЕЛ». «Ветер дня» отложен (В20) |

Нижних вкладок нет (В1).

## Курс-тропа

- **Тропа** из 13 узлов: 00 вводное и 01–12 с допуском. Идёт сверху вниз, плавной линией.
- **Узел:** номер, название, штамп класса — золото, серебро, бронза. Текущий узел пульсирует. Следующий открыт. Остальные закрыты пунктиром с замком.
- **00 «Винтовка и прицел»** — без штампа, отметка «пройдено».
- **Шапка:** «СНАЙПЕРСКАЯ ПОДГОТОВКА», «Пройдено 4 / 12» и звание.
- **Кнопки «ПРОДОЛЖИТЬ» на тропе нет** (В28: одна функция — одно место, она на главном экране). Текущий узел выделен, тап по нему — брифинг (06).
- **Тап по пройденному узлу** — брифинг этого упражнения для повтора.
- **12 «Полевой рубеж»** — особый узел: «аттестация», рядом знак звания «Снайпер».

## Состояния

| Состояние | Что |
| --- | --- |
| Первый запуск | открыт только 00; на главном — карточка «НАЧАТЬ · 00 ВИНТОВКА И ПРИЦЕЛ» |
| В процессе | текущий узел, остальное по прогрессу |
| Курс пройден | все узлы со штампами, звание «Снайпер» или «Снайпер-инструктор»; на главном — карточка «СВОБОДНАЯ ИГРА» |
