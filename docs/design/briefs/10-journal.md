# 10 · Журнал стрелка

**Зачем.** Достижения и разбор ошибок: где ты стабильно ошибаешься и почему (Б8). Блокнот — для стрельбы, журнал — архив и личное дело.

**Вход и выход.** Меню 04 (08), «В ЖУРНАЛ» из итога (07).

Референс: [прибор и бумага, артборд 8](https://claude.ai/artifact/Jtd51vsnZTP5TXYgiZ74GK).

## Разделы (табы сверху, прибор; листы — бумага)

| Таб | Содержание |
| --- | --- |
| ЛЕНТА | серии по датам. Серия: упражнение или «свободная», патрон, класс-штамп. Внутри строки выстрелов, как в учебном журнале: № · дист · ВЕРТ · ГОР · вызов ✛ · попадание ● на мини-мишени · очки · замечание. Тап по выстрелу — разбор (05) и проверка (04) этого выстрела. Пометки «прервано» (В15) и «спуск тапом» (В19) |
| ОШИБКИ | разбор ошибок по типам за всё время: СТОРОНА, ПОДСТАНОВКА, АРИФМЕТИКА, ФАКТОР, ПОКАЗАНИЯ, УПРЕЖДЕНИЕ, спуск, дыхание. Для каждой: сколько раз, последний пример с объяснением «где прокосячил», ссылка на главу учебника. Самая частая — сверху красным карандашом |
| КАРТОЧКИ | карточки ДОПЕ по патронам: заводские значения чернилами + записи игрока графитом (Б7) |
| СТАТИСТИКА | попадания первым выстрелом по дистанциям (100–1000 м, столбики), по силе ветра, по режиму; рекорды упражнений; «шанс» и «удача» по выстрелам (В12) |
| ДОСТИЖЕНИЯ | звания со знаками, классы по упражнениям, рекорды |

## Состояния

| Состояние | Что |
| --- | --- |
| Пусто | один лист: «Журнал пуст. Первая запись — после упражнения 01» и кнопка «К КУРСУ» |
| Мало данных для статистики | меньше 10 выстрелов — «наберётся после 10 выстрелов» |

## Нельзя

- Нельзя: дублировать блокнот: расчёта в журнале нет, только записи (правило README).
