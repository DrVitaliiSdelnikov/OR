# 06 · Брифинг и подсказки инструктора

**Зачем.** Перед упражнением объяснить задание и зачёт, а во время упражнения вести игрока подсказками.

**Вход и выход.** Брифинг открывается тапом по узлу курса (08) перед каждым запуском (В16). «НА ПОЗИЦИЮ» ведёт сразу в секцию стрелка (01), экрана «Позиция» нет (В2).

Референсы: [игровой слой, брифинг](https://claude.ai/artifact/S5PTbWpgZRp3GPR9oJAmsd), [прибор и бумага, артборд 1](https://claude.ai/artifact/Jtd51vsnZTP5TXYgiZ74GK).

## Брифинг — бумажная карточка задания

| Блок | Содержание |
| --- | --- |
| Шапка | «ЗАДАНИЕ 04 · УЧЕБНОЕ», название «Флажок на бруствере» |
| Схема | «ты → гонг 300 м» сбоку, флажок у бруствера |
| Условия | цель (гонг 0,5 м · 300 м) · ветер (слабый, «замерь станцией») · условия — только T и P («+14 C · 1015 гПа»; слово «штиль» — только если ветра нет) · патронов 3 × 2 |
| Шапка аттестации | для 12 «Полевой рубеж» — «ЗАДАНИЕ 12 · АТТЕСТАЦИЯ», схема с целями на 200–700 м; строки «узнаешь» нет: новых терминов упражнение не открывает |
| Зачёт | три цели классов с нормативом из [COURSE](../../logic/COURSE.md): «3 класс — от 70 % очков · 2 класс — 85 % и скорость перенесена без ошибки · 1 класс — вклад ветра учтён на всех» |
| Режим | АВТО / САМ · лёгкий / сложный (если упражнение разрешает выбор) и множитель |
| Новое | «Новое: ветер и правило часов» — только при первом запуске |
| Переключатель | «с инструктором» — включает подсказки при повторе |
| Штамп | «к исполнению» |
| Кнопка | «НА ПОЗИЦИЮ» латунью — видна без прокрутки |

Ниже карточки — ссылки на термины, которые откроет упражнение: «узнаешь: правило часов · флажок · метеостанция».

## Подсказки инструктора (И1, В16)

**Плашка «по рации».**
- Строка сверху экрана на тёмной плашке, Roboto Mono, слева значок рации и позывной «Старший».
- Пример: «Старший: ветер слева — бери влево».
- 3–7 слов на «ты». Гаснет через 4 с или по тапу. Важная реплика — с вибрацией.

**Обучающая подсказка (упр. 00–03 и всё новое).**
- Затемнение экрана, вырез под один элемент, карточка инструктора рядом с вырезом.
- Подсказка с действием («Крути барабан: 4 клика вверх») гаснет, когда действие сделано.
- Поясняющая подсказка закрывается по «ПОНЯЛ».
- Всё вне выреза заблокировано, кроме мелкой «пропустить обучение» в углу.
- На плашке «подсказка 3 из 8».
- В тексте подсказки термины подчёркнуты пунктиром и открывают карточку учебника шторкой, не прерывая подсказку.
- Числа в подсказках — из расчёта, а не из текста (В7).

## Состояния

| Состояние | Что |
| --- | --- |
| Первый запуск | строка «Новое», подсказки включены |
| Повтор | без «Новое», подсказки выключены, переключатель «с инструктором» |
| Упражнение без выбора режима | строка режима — текстом, без переключателя |

## Нельзя

- Нельзя: подписи классов мелким серебряным или бронзовым текстом (контраст ниже 4,5:1, TOKENS). Текст — чернилами, цвет класса — маркером рядом.
- Нельзя: плашкой рации сдвигать шапку и стекло — она поверх.

- Нельзя: зачёт «3 попадания» — только три цели классов.
- Нельзя: мишень «1 м» — размеры по [FORMULAS](../../logic/FORMULAS.md) и COURSE.
