# 07 · Итог упражнения

**Зачем.** Сказать, как прошло упражнение целиком: класс, цели, главная ошибка, что открылось.

**Вход и выход.** Открывается после «ДАЛЬШЕ» в разборе последнего выстрела (05). Выход:
- «ДАЛЬШЕ» — к следующему узлу курса (08);
- «ПОВТОРИТЬ» — на брифинг (06);
- «В ЖУРНАЛ» — запись серии в журнале (10).

## Состав — бумажный лист со штампом (В17)

| # | Блок | Как выглядит |
| --- | --- | --- |
| 1 | Штамп | «1 КЛАСС» (stamp-gold) / «2 КЛАСС» (stamp-silver) / «3 КЛАСС» (stamp-bronze) / «НЕ ЗАЧТЕНО» (red-pencil). Крупно, под углом 4–6°, удар и вибрация при появлении |
| 2 | Три цели | ✓ или ✕ и факт графитом: «≥ 70 % очков — 85 % ✓ · скорость без ошибки ✓ · вклад ветра на всех — 2 из 3 ✕» |
| 3 | Очки | строка по [FORMULAS, «Оценка»](../../logic/FORMULAS.md#оценка): «цели 35 + расчёт 35 = 70 × 1.5 = 105»; процент класса — только по целям; рекорд упражнения |
| 4 | Мишень серии | все попадания ● и вызовы ✛ на одной схеме; группа и диагноз основ (из 05) |
| 5 | Главная ошибка | одна строка красным карандашом: «3 из 5 — недооценка ветра» → термин учебника |
| 6 | Новое | открытые термины учебника (появляются по одному: «новый термин»); следующий узел на тропе |
| 7 | Кнопки | «ДАЛЬШЕ» (латунь) · «ПОВТОРИТЬ» · «В ЖУРНАЛ» |

Числа серии — из COURSE: сколько целей и какой режим у этого упражнения (03 — 5 гонгов, АВТО × 1.0). Главная ошибка не противоречит штампу: при 1 классе вместо неё строка «Ошибок нет».

## Состояния

| Состояние | Что |
| --- | --- |
| 1 / 2 / 3 класс | штамп класса, «ДАЛЬШЕ» главная |
| Не зачтено | штамп красным, следующий узел не открывается, «ПОВТОРИТЬ» становится главной, «ДАЛЬШЕ» скрыта |
| Новое звание | после штампа отдельной плашкой: «Звание: Стрелок» и знак (В20, COURSE) |
| Повтор с улучшением | старый класс зачёркнут графитом, новый штамп рядом |
| Упр. 00 | итога нет: упражнение без оценки |

**Источники:** В17, В20, В4, [COURSE](../../logic/COURSE.md).
