# 01 · Секция стрелка

**Зачем.** Главный игровой экран: прицел и всё, что нужно для выстрела, без перехода на другие экраны.

**Вход и выход.** Вход — «НА ПОЗИЦИЮ» с брифинга (06) или «ЗАНЯТЬ ПОЗИЦИЮ» из свободной игры (09). Промежуточного экрана «Позиция» нет (В2). Выход:
- «назад» — туда, откуда пришёл (В15);
- после выстрела — разбор (05) шторкой;
- после последнего патрона — итог (07).

Референсы: [секция стрелка, вариант A](https://claude.ai/artifact/3SwA4HdLv5j6U2gAUDHdk5), [спуск и затвор](https://claude.ai/artifact/VcArQgrtghpJwVMq1faPnr).

## Состав сверху вниз (Б1 — гибрид A + шторка)

| Зона | y, pt | Что |
| --- | --- | --- |
| Шапка | 18–66 | слева «назад» 48 × 48. По центру название («Упр. 04 · Флажок на бруствере» / «Свободная стрельба») и подпись «рубеж · 300 м». Справа плитка ветра «3.2 м/с · 9 ч» с мини-циферблатом — тап открывает блокнот на вкладке ВЕТЕР |
| Строка поправок | 74–108 | ячейки ВЕРТ · ГОР · ДИСТ, при надобности УДЕРЖ. (Б4) |
| Стекло | ≈ 110–600 | оптика: кольцо, сцена, сетка. Барабаны на корпусе: верхний (ВЕРТ) над стеклом, боковой (ГОР) справа, кольцо кратности под стеклом (Б13, В14). Над каждым барабаном — метка-цель и счётчик |
| Плитки | ≈ 610–680 | «ДОПЕ · 300 м ↑ 1.2» и «БЛОКНОТ · итог» — тап открывает шторку на нужной вкладке |
| Огонь | 696–796 | слева «ДЕРЖАТЬ» Ø 84, справа «ОГОНЬ» Ø 100. Счётчик патронов «4 / 5» мелко у «ОГОНЬ». Для левши — зеркально (В19) |

Плашка инструктора (И1) появляется поверх шапки, стекло не закрывает.

## Строка поправок (Б4)

- Значение — **накрученное** на барабанах: с ним полетит пуля.
- Пока не докручено до итога блокнота, рядом латунью цель: «ВЕРТ ↑ 0.8 → 1.1».
- Докручено ровно — значение белое, хвоста нет.
- Блокнот пуст — «→ —».
- Ячейка «УДЕРЖ. ↑ 0.4» — только когда барабану не хватило хода.
- Стрелка всегда указывает направление поправки: «← 0.4 L» (В13).

## Барабаны (Б3, Б13)

- На корпусе видна узкая лента шкалы, латунный индекс и красная зона ZERO STOP.
- **Свайп** вдоль ленты — клики: ≈ 1 клик на 12 pt, быстрый свайп — с инерцией.
- **Тап** — лупа: барабан крупно, на ⅔ ширины, над корпусом. Сама закрывается через 1,5 с.
- **Метка-цель** — латунный треугольник на шкале там, где итог блокнота. Над барабаном счётчик «ещё 4 кл. ←»; перекрутил — «лишние 2 кл.». На цели метка гаснет.

## Огонь (Б12)

- **«ДЕРЖАТЬ»** — задержка дыхания. Кольцо вокруг кнопки показывает остаток воздуха, после выдоха — пауза (кнопка приглушена).
- **«ОГОНЬ»** — спуск с давлением: держишь — давишь. Кольцо давления вокруг кнопки, зона спуска вокруг перекрестия в стекле.
- **Затвор.** После выстрела на месте «ОГОНЬ» появляется рукоять затвора на Г-дорожке: вверх → назад → вперёд → вниз. Шаги подписаны, над дорожкой анимация силуэта ствольной коробки. Дослал — «ОГОНЬ» вернулся, счётчик 4 / 5.
- В упр. 01–02 «ОГОНЬ» — тап, затвор работает сам.

## Состояния

| Состояние | Что меняется |
| --- | --- |
| Подготовка | блокнот не заполнен: на плитках точка «не заполнено», строка «→ —» |
| Докрутка | метки на барабанах, счётчики «ещё N кл.», цель латунью в строке |
| Готов | всё докручено, строка белая |
| Дыхание | кольцо воздуха убывает, качка сетки затихает |
| Спуск | кольцо давления растёт, зона вокруг перекрестия |
| После выстрела | на месте «ОГОНЬ» — затвор; поверх выезжает разбор (05) |
| Удержание | ячейка «УДЕРЖ.» в строке |
| Движущаяся цель (М1) | цель плывёт поперёк; в строке ячейка «УПРЕЖД. ← 1.8 сеткой» — только напоминание, барабан не трогает |
| Патроны кончились | итог упражнения (07) или, в свободной игре, «сменить магазин» (Б33) |
| Подсказка обучения | затемнение с вырезом под элемент (06) |
| Шторка открыта | стекло видно сверху, низ занят блокнотом (02) |

## Взаимодействие

- Щипок по стеклу — кратность: щелчок на целых, «12×» у кольца.
- Системная «назад» закрывает слои по очереди: лупа → шторка → разбор → выход с подтверждением (В15).
- Звук и вибрация — по таблице в TOKENS.

## Важно / нельзя

- Нельзя: кнопку, которая сама крутит барабан (Б3).
- Нельзя: дублировать итог блокнота второй строкой.
- Нельзя: закрывать перекрестие плашками.
- Важно: всё, что нужно до выстрела, — на одном экране, большие пальцы достают до «ДЕРЖАТЬ», «ОГОНЬ» и барабанов.

**Источники:** Б1, Б3, Б4, Б12, Б13, В13, В14, В15, М1, И1.
