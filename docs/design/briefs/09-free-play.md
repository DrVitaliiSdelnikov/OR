# 09 · Свободная игра

**Зачем.** Стрельба без курса: игрок сам задаёт условия.

**Вход и выход.** Вход из меню 02 (08). «ЗАНЯТЬ ПОЗИЦИЮ» ведёт в секцию стрелка (01). Выход с позиции возвращает сюда (В15).

Референс: [игровой слой, «Свободная игра»](https://claude.ai/artifact/S5PTbWpgZRp3GPR9oJAmsd).

## Состав сверху вниз (В9)

| Блок | Содержание |
| --- | --- |
| Шапка | «назад», «СВОБОДНАЯ ИГРА», подпись «параметры выстрела» |
| Дистанция | крупно «600 м» (`type.hero`), ползунок 100–1000 м шагом 50 со щелчками. Переключатель «неизвестная»: игра выберет сама, мерить по сетке |
| Ветер | плитки: штиль · слабый · умеренный · сильный · порывистый |
| Прицел и патрон | две плитки, по тапу — лист выбора (каталог прицелов, патроны А / Б / В с одной строкой характеристик) |
| Режим блокнота | АВТО · САМ лёгкий · САМ сложный, множитель |
| Инструктор рядом | переключатель. Включён — подсказки по ходу и строка «Расчётные данные: поправка ~ 2,4 MIL». Выключен — строки нет |
| Кнопка | «ЗАНЯТЬ ПОЗИЦИЮ» латунью |

Время суток и небо не показываем: пока всегда день и ясно (В9, «Отложено»).

## Закрытое до курса

Закрытые элементы видны с замком и подписью «откроется в упр. N»:
- «неизвестная» дистанция — после 05;
- «порывистый» ветер — после 09;
- САМ · лёгкий — после 06;
- САМ · сложный — после 10;
- патроны А и В — после 08;
- MOA-прицел — после 06.

## Во время игры

- Смена патрона — только между выстрелами, это смена магазина: счётчик 5 / 5, новая серия (Б33).
- Патроны кончились — «сменить магазин».
- Серия уходит в журнал при выходе.

**Источники:** В9, Б33, В15, [COURSE](../../logic/COURSE.md) (что когда открывается).
