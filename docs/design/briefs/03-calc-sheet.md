# 03 · Лист расчёта: АВТО и САМ

**Зачем.** Шаг расчёта одного фактора: формула, подстановка, арифметика. Это сердце режима САМ.

**Вход и выход.** Открывается из строки фактора в хабе (02). «ЗАПИСАТЬ» (САМ) или «ПОСЧИТАТЬ» (АВТО) возвращает в хаб. Проверки до выстрела нет: только «записано» (Б16).

Референсы: [подсчёт](https://claude.ai/artifact/FqAPuDczXzTZKW2jbirezT) (основа — вариант А «лоток», из Б — лента арифметики и группировка чипов), [прибор и бумага](https://claude.ai/artifact/Jtd51vsnZTP5TXYgiZ74GK) (артборды 5–6).

## Состав сверху вниз

1. **Заголовок шага** «Ветер · шаг 3 из 4» и плашка режима «САМ · ЛЁГКИЙ ×1.5».
2. **Бумажный лист:**
   - формула печатью (чернила): W = V⊥ × D / K (FORMULAS);
   - строка подстановки со **слотами** [ ] — пустой пунктирный, активный с карандашом, заполненный графитом;
   - **лента арифметики** ниже: «V⊥ × D = ___» → «÷ K = ___» → «до клика 0.1 = ___» и сторона ← / →.
3. **Лоток переменных** — прибор, под листом:
   - чипы 44 pt: значение + подпись источника («3.2 · V⊥ после часов», «300 м · D дальномер», «2400 · K карточка патрона»);
   - тап — чип встаёт в активный слот, тап по слоту — вынуть;
   - если чипов больше пяти — группы «приборы · расчёт шагов · патрон».
4. **Клавиатура** — только для чисел ленты арифметики, не для подстановки. Кнопки сторон «← ВЛЕВО / ВПРАВО →» и единицы «MIL ▾».
5. **Кнопки:** «ФОРМУЛЫ» (справочник) и главная «ЗАПИСАТЬ».

## Три режима (Б17, Б17а)

| | АВТО | САМ · лёгкий | САМ · сложный |
| --- | --- | --- | --- |
| Формула | выписана | выписана, константа видна | константа в слоте: W = [ ] × [ ] / [ ] |
| Подстановка | игрой, чернилами, со штампом «подставлено игрой» и подписью источников | игроком, тапом | игроком, тапом |
| Чипы | не нужны | только нужные, слот подсвечивает, какой чип ждёт | нужные + 2 ловушки, без подсветки |
| Арифметика | по кнопке «ПОСЧИТАТЬ», лента заполняется чернилами | игрок, клавиатурой | игрок, клавиатурой |
| Подсказка | — | мягкая, без ответа: «какая дальность идёт в ветер?» | нет |
| Справочник | открыт | открыт | «ФОРМУЛЫ −30» |

**Ловушки сложного режима — честные:** в шаге ветра рядом с V⊥ лежит V (набор «В»: 1,6 и 3,2), рядом с D — дальность до соседней цели, плюс лишние T и P. Ловушка D′ / D (Б32) — только когда появится вкладка УГОЛ.

## Шаги расчёта (первый релиз)

| Шаг | Формула (FORMULAS) | Чипы |
| --- | --- | --- |
| Дистанция | Д = размер × 1000 / MIL | размер цели из брифинга, MIL с сетки |
| ДОПЕ | строка карточки по дистанции (с углом — по D′, позже); между строками — пропорция | строки карточки |
| Атмосфера | ΔВЕРТ = ДОПЕ × (K_атм − 1) | T, P со станции, ДОПЕ из шага 2 |
| Ветер | V⊥ = V × доля; W = V⊥ × D / K | V, часы, D, K |
| Упреждение (М1) | L = V⊥ цели × t / D × 1000 | скорость цели, t из карточки, D |

## Важно / нельзя

- Нельзя: кнопку «ПРОВЕРИТЬ» до выстрела — только «ЗАПИСАТЬ» (Б16). На холстах это поправить (CANVAS-FIXES).
- Нельзя: ветер по D′ (Б32).
- Нельзя: печатать на листе правильный ответ в САМ.
- Важно: видно, кто записал каждое число — чернила (игра) или графит (игрок).
