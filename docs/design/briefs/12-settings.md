# 12 · Настройки

**Зачем.** Звук, управление, доступность и значения по умолчанию.

**Вход и выход.** Шестерёнка на главном экране (08). Экран — прибор, тёмный (В19).

## Группы

| Группа | Пункты |
| --- | --- |
| Звук и вибрация | громкость (ползунок со щелчками), вибрация вкл / выкл, щелчки барабанов вкл / выкл |
| Управление | левша — «ДЕРЖАТЬ» и «ОГОНЬ» меняются местами (показать мини-схему); чувствительность барабанов: клик на 8 / 12 / 16 pt |
| Доступность | спуск тапом вместо давления (подпись: «очки не снижает, отмечается в журнале»), крупный текст |
| По умолчанию | режим блокнота: АВТО / САМ лёгкий / сложный; единицы прицела в свободной игре: MIL / MOA |
| Данные | сброс прогресса — с подтверждением «Сбросить курс, журнал и карточки? Это не отменить»; версия |

Темы нет: одна тёмная (В23).

**Источники:** В19, В23.
