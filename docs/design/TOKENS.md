# Токены стиля «прибор и бумага»

Выписаны из холстов (главный — [Прибор и бумага](https://claude.ai/artifact/Jtd51vsnZTP5TXYgiZ74GK)) и выровнены по нормам В24. Статус: черновик, дизайнер утверждает (В23). Код берёт токены отсюда, брифы на них ссылаются.

## Принцип (Б10)

- **Прибор** — тёмное, моно. Это всё, что считает и управляет: рамка, табы, кнопки, чипы, клавиатура, прицел.
- **Бумага** — тёплое. Это всё, что читают и пишут: листы ИТОГ, ДОПЕ, расчёт, проверка, журнал, брифинг, учебник.
- **Кто пишет — тем цветом:** чернила — игра, графит — игрок, красный карандаш — проверка.

## Шрифты (В25)

| Роль | Шрифт | Где |
| --- | --- | --- |
| Заголовки | Roboto Condensed 700, капс, разрядка 0,05 em | названия экранов, табы, штампы |
| Числа и метки | Roboto Mono 500 / 700 | все числа, поправки, клики, метки капсом с разрядкой 0,07 em |
| Текст | Roboto 400 / 500 / 700 | фразы, пояснения |

Рукописных шрифтов нет: Caveat и Roboto Slab не используются. Графит — тем же Roboto Mono, другим цветом и со значком карандаша.

| Размер | pt | Где |
| --- | --- | --- |
| `type.min` | 13 | минимум для любого текста (метки 11–12 на холстах поднимаются) |
| `type.label` | 13 | метки капсом |
| `type.body` | 15 | фразы |
| `type.value` | 17 | значения в плитках |
| `type.title` | 22 | заголовок экрана |
| `type.big` | 28 | итог проверки, очки |
| `type.hero` | 40 | крупное значение (дистанция в свободной игре) |

**Крупный текст** (настройки, A7.4): `type.label`, `type.body`, `type.value`, `type.title` × 1,15 с округлением — 15, 17, 20, 25. `type.min`, `type.big`, `type.hero` не меняются. В коде — `:root[data-text='large']`.

## Движение (В26)

| Что | Как |
| --- | --- |
| Переход меню → позиция | «приближение в прицел»: затемнение по кругу окуляра, ≤ 300 мс |
| Шторка блокнота | выезд снизу, 240 мс, щелчок |
| Бумажный лист | сдвиг листа, 200 мс |
| Штамп | удар: масштаб 1,2 → 1, 120 мс, вибрация |
| Подсказка инструктора | появление сверху 160 мс, гаснет через 4 с |
| Фон главного | сетка качается (модель качки × 0,2), дымка по горам |
| Всё | ≤ 300 мс; с «уменьшить движение» в системе — без масштаба и сдвигов, только прозрачность |

## Звук и вибрация (Б13, В26)

| Событие | Вибрация | Звук |
| --- | --- | --- |
| Клик барабана | selectionChanged (как пикер iOS) | короткий сухой тик |
| Целый MIL на барабане | selectionChanged | тик громче |
| Полный оборот барабана | impact light | тик громче |
| Упор ZERO STOP | impact medium | глухой щелчок |
| Получас на «часах» ветра, шаг пикера скорости | selectionChanged | тик |
| Кратность, целое значение | selectionChanged | тик |
| Выстрел | impact heavy | выстрел + хвост эха |
| Попадание / промах | — | звон гонга / глухой удар в вал; задержка — время полёта + путь звука (ядро) |
| Пустой патронник | notification warning | сухой щелчок |
| Затвор, каждый из 4 шагов | impact light | свой звук шага |
| Гильза | — | звон |
| Магазин | impact medium | щелчок магазина |
| Штамп | impact medium | удар штампа |
| Реплика инструктора, важная | notification warning | писк рации |
| Кнопки, шторка блокнота | — | сухой щелчок |

В коде вся таблица — `FEEDBACK_PLAN` в `app/services/feedback.model.ts`; попадание и промах — `FeedbackService.scheduleImpact`.
