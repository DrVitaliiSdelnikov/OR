# app · позиция (секция стрелка), часть 1: каркас и упражнения 01–02

Статус: реализовано 8.11, слито в `master`. Юнит-тестов 459, e2e 72 (по 36 на mobile-chromium и mobile-webkit) — все зелёные.
Задача бэклога: A3.1 (A3 разбит: A3.1 — каркас позиции и упр. 01–02; A3.2 — спуск и затвор по Б12, открывает 03). Решения: Б1, Б3, Б4, Б12, Б13, В13, В14, В15, Б31, В31. Бриф [01](../../design/briefs/01-shooter.md). Логика: `sim/course` (S8), `sim/firing-line` (S6–S7), `sim/notebook` (S9), `sim/turret-target` (S1), `sim/shot-review` (S2–S5), `core/shot` (C8, холодный выстрел, сбитый ноль).

## Зачем

Первая игровая позиция на новой логике: «НА ПОЗИЦИЮ» с листа упражнения → стрельба по целям упражнения → класс пишется в прогресс → штамп на тропе. Пока только упражнения, где хватает того, что уже есть: 01 и 02 (штиль, известная дистанция, спуск тапом и затвор сам — так по COURSE и Б12).

## Правила (решено мной)

- **Маршрут** `/position/:exerciseId`. Кнопка «НА ПОЗИЦИЮ» на листе активна только для играбельных упражнений: сейчас 01 и 02. Играбельность считается из того, что упражнению нужно (спуск с давлением, ввод в блокнот при ветре, движущиеся цели, вводное), против списка сделанного `IMPLEMENTED_FEATURES` в `position.model` — без списка номеров. Список растёт с A3.2, A5, A7, A9 и уходит, когда играбельно всё.
- **Постановка:** `setupExercise(def, seed)`, зерно — новое на каждую попытку. Сценарий — `createScenario(seed, setup.scenarioOptions)`. Прицел — `def.scopeId`. Карточка ДОПЕ — `buildDopeCard` патрона этапа, кэш на сессию.
- **Ход стрельбы — `FiringLine`** (S6): текущая цель, патроны, магазин, конец упражнения. Затвор `BoltAction` заряжается из `FiringLine`: в патроннике 1, в магазине `magazineLoaded − 1`. `ScopeSession` получает число патронов параметром (сейчас зашито 4 + 1 — кандидат на удаление из REMOVAL-CANDIDATES закрывается).
- **Спуск тапом и затвор сам** (01–02): тап «ОГОНЬ» — выстрел без площадки (`ScopeSession.fire()` без `TriggerPull`: дрожь спуска 0). После выстрела затвор досылает сам — новый `BoltAction.cycle()` (мгновенный полный цикл: выброс, подача, запирание; события те же, что у ручного). Признак механики — новое поле курса `ExerciseDef.trigger: 'tap' | 'pressure'` (01–02 — `tap`, с 03 — `pressure`).
- **Выстрел:** `resolveShot(…, { timeS, hold, isColdBore: firingLine.isNextShotCold, sightOffset: setup.sightOffset })`. Вызов = `FireOutcome.hold`; диагноз — `diagnoseShot` (S4).
- **Запись выстрела курса** — `ExerciseShotRecord` (S8): этап, цель, дистанция, попадание, холодный, попадание в MIL, диагноз; для 01 — `isDialExactFirstTry` (ниже). В старый журнал (`ShotRecord` с `verdict`) не пишется — журнал курса в A7.
- **«Накрутка ровно с первого раза»** (01): у первого выстрела по цели барабаны стоят ровно на цели блокнота, и при докрутке к этой цели не было перекрута (`turretProgress.overshootClicks` ни разу > 0).
- **Цель барабанов** — `total(notebook)` (S9) в АВТО: контекст — карточка, прицел, цель (размер, дистанция). Новая цель (`next-target`) → `changeContext` → метки переезжают; барабаны не трогаются (Б3).
- **Конец упражнения** (`exercise-done`) → `exerciseResult(def, run)` (S8) → `progress.recordExerciseResult(id, класс)` → карточка «класс N · очки · не зачтено / допуск» и кнопки «К ТРОПЕ», «ЕЩЁ РАЗ».
- **Выход** «назад»: до первого выстрела — сразу; после — подтверждение «Покинуть позицию? Упражнение не засчитается» (В15) — своей карточкой, не `window.confirm`.

## Граничные случаи

- 01: 3 гонга × 2. Попал первым по цели 1 — цель 2, метки на барабанах на той же высоте (та же дистанция).
- 01: промах, промах по цели — `target-closed`, следующая цель; патроны: 6 на 3 цели, магазин 5 → после 5-го выстрела «СМЕНИТЬ МАГАЗИН» (1 патрон).
- 02: сбитый ноль — попадания уходят на 0,5–1,5 MIL; цель блокнота ВЕРТ 0 (100 м), перенос СТП — сам игрок по группе; 5 выстрелов, первый холодный.
- Выход после выстрела без подтверждения — нельзя; после конца упражнения — без подтверждения.
- Повтор («ЕЩЁ РАЗ») — новое зерно, новый `FiringLine`, барабаны в ноль.
- Нет итога блокнота (не бывает в 01–02, но модель умеет) — строка «→ —», меток нет.

## Кандидаты на удаление

- «заряжание `ScopeSession.bolt` 4 + 1» — закрывается: патроны параметром; значение по умолчанию держит только старый прицел свободной игры, уходит вместе с ним (A5 / A7).
- `IMPLEMENTED_FEATURES` и `playability` — временные, уходят, когда играбельно всё (A9).
- Карточка итога и строка «попадание / промах» — временные до A6 (разбор 05, итог 07); помечаются в REMOVAL-CANDIDATES «будет заменено».

## Как сделано

- `PositionSession` (чистый TS) — постановка, `FiringLine`, блокнот АВТО, `ScopeSession`, выстрел через `resolveShot` с холодным выстрелом и сбитым нолём, записи `ExerciseShotRecord`, итог. Весь ход упражнения проверяется юнит-тестами с настоящим ядром.
- `ScopeSession(…, loadedRounds)` — патроны параметром; `BoltAction.cycle()` — автозатвор; `ExerciseDef.trigger`.
- Экран `position.page` и `turret-drum` — только токены; общий со старым прицелом только рендер стекла и `FeedbackService`.
- Играбельность — `playability(def)` против `IMPLEMENTED_FEATURES` (вместо списка номеров из черновика: не надо помнить, какие упражнения что требуют).
- Тест A2 «НА ПОЗИЦИЮ неактивна у 01» заменён: 01 теперь играбельно — смена правила.
- Проверено по снимку (`docs/design/screens/19-position.png`), не тестами: боковой барабан был сжат до ~90 px (`align-items: center` у сетки барабана) и не вмещал значение; счётчик патронов прижимался к краю экрана. Исправлено: барабан тянется на высоту стекла, ширина 64 (за счёт оправы стекла 4 pt — само стекло 276 pt не меняется, от него зависит перевод жестов в MIL), счётчик — у «ОГОНЬ».
- e2e: перед «сырыми» жестами мышью — `click({ trial: true })`: после перехода с листа Ionic ещё анимирует страницы, и события уходили в уходящую страницу (код не менялся). На WebKit быстрый свайп по барабану с инерцией перекручивает мимо цели — тест барабана смотрит на значение барабана (`aria-valuenow`), а не на текст счётчика.

## Мутации

36 мутаций (28 юнит, 8 e2e). Сначала выжили 6:
- три эквивалентные — код упрощён: сброс шага затвора в `cycle()` (в покое затвор и так на первом шаге); «блокнот нужен при неизвестной дистанции или САМ» (в курсе таких упражнений в штиль нет — решает ветер); проверка пустого магазина в `fire()` (пустой магазин — пустой патронник, затвор не даст выстрелить);
- три закрыты тестами: ячейка УДЕРЖ. при упоре только по горизонтали; «с первого раза» — только первый выстрел по цели; диагноз по вызову, а не по попаданию (сетка на цели, барабан не накручен — «данные»).
