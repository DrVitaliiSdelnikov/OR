# core · снаряжение вместо глобальной винтовки

Статус: реализовано 15.11, ветка `feat/loadout`. Новых юнит-тестов 10 (7 `core/loadout.spec`, по одному в `shot`, `flight-path`, `shot-review`), мутаций 11 — все красят. Старые тесты зелёные без правки чисел (358 в связанных спеках).
Задача бэклога: T1.2. Решение: В34 (свой профиль винтовки). Перед: T1.1. Дальше: T1.3 (деривация берёт шаг нарезов и длину пули), T1.5 (профиль собирает снаряжение).

## Зачем

Сейчас винтовка одна на всё приложение: `RIFLE` в `core/content.ts`. Её высоту прицела и ноль берёт движок, разброс и смещение холодного ствола — выстрел, высоту прицела — схема полёта. Калибр лежит в винтовке, хотя это свойство пули. Своего профиля (T1.5) при этом не сделать: движок не знает, какой винтовкой стреляют.

## Правила (решено мной)

- **`Loadout = { rifle, cartridge }`** — то, чем стреляют. Это всё, что нужно баллистике. Прицел не входит: он уже выбирается упражнением (`scopeId`, S11), на траекторию не влияет, а в профиль войдёт в T1.5.
- **`Rifle`:** имя, высота прицела, дистанция нуля, разброс винтовки, смещение холодного ствола, **шаг нарезов** (дюймов на оборот) и **направление нарезов** (`right` / `left`).
- **`Cartridge`:** к нынешним полям добавляются **калибр** (переезжает из винтовки), **длина пули** (мм) и **модель сопротивления** `dragModel: 'G1' | 'G7'` с коэффициентом `ballisticCoefficient` вместо `bcG7`. Тексты учебника и свободной игры берут подпись модели из поля, а не пишут «G7» сами.
- **Ключ кэша нуля** вычисляется из чисел, от которых ноль зависит: высота прицела, дистанция нуля, калибр, масса, модель, BC, скорость. Ручного ключа нет: поменяли профиль — получили новый ноль; два профиля с одинаковыми числами делят один ноль.
- **`BallisticsEngine.trajectory(loadout, atmosphere, windZones, muzzleVelocity?, step?)`.** Остальные входы прежние.
- **Учебное снаряжение:** `COURSE_RIFLE` (нынешние числа `RIFLE` + шаг 10″, нарезы правые) и `courseLoadout(cartridgeId)`. Патроны А, Б, В получают калибр 0,308″ и длину пули 28,5 / 31,2 / 32,5 мм (правдоподобно для 9,7 / 10,9 / 11,7 г). Шаг и длина пока ничего не меняют: их берёт деривация в T1.3.
- **Вызовы `RIFLE` уходят на снаряжение задачи:** `resolveShot` и `buildDopeCard` принимают `loadout`; `flightPaths` и `shotReview` получают высоту прицела и разброс от вызывающего. Экраны курса берут `courseLoadout(firingLine.cartridgeId)`, тексты учебника — `COURSE_RIFLE`.
- **`RIFLE` → `@deprecated`** и строка в REMOVAL-CANDIDATES (удалить в T1.5). Импортов у него не остаётся.
- **`CartridgeId` остаётся `'A' | 'B' | 'C'`.** В бэклоге было `string`, но произвольный патрон появится только в профиле (T1.5). Сейчас ослабление типа ничего не даёт, а проверки каталога (`satisfies Record<CartridgeId, …>`) потеряют силу. Тип расширяется в T1.5 вместе с профилем.
- **Числа курса не меняются:** ДОПЕ А, Б, В, выстрелы и разборы прежние.

## Тесты (сначала, каждый с мутацией)

| Тест | Мутация, которая красит |
| --- | --- |
| **регрессия ДОПЕ:** строки А, Б, В на 100–1000 м (возвышение, снос на 1 м/с, время полёта) совпадают до 0,01 со снимком, снятым на `master` до правки (`core/course-dope.regression.json`) | высота прицела 5,1 см вместо 5 |
| ключ нуля: снаряжение с нулём 200 м даёт другую траекторию, чем 100 м, тем же движком и после него | ключ кэша по `cartridge.id` |
| ключ нуля: два одинаковых по числам снаряжения → один ноль (пристрелка один раз) | ключ из ссылки на объект |
| модель сопротивления: тот же BC в G1 даёт другое возвышение на 800 м, чем в G7 | таблица всегда G7 |
| выстрел: разброс и холодный ствол — из винтовки снаряжения (холодный ствол другой винтовки → другой `coldBore`) | вернуть `RIFLE` в `shot.ts` |
| схема полёта: дуло ниже линии прицела на высоту прицела снаряжения | вернуть `RIFLE.sightHeightCm` |
| `courseLoadout`: А, Б, В — общая `COURSE_RIFLE`, калибр 0,308″, G7 | патрон другой винтовкой |
| нет импортов `RIFLE` вне `core/content.ts` (охранник, как `catalog-guard`) | импортировать `RIFLE` в любом файле |

Старые юнит-тесты должны остаться зелёными без правки чисел; меняются только вызовы (`courseLoadout` вместо `cartridgeById`). Тест упадёт на числах — останавливаюсь и ищу причину, а не правлю ожидание.

## e2e

Новых нет: экраны не меняются. Связанные на сборке: `position`, `review`, `journal`, `textbook`, `term-schemes`, `free-play`, `patrol` — они строят ДОПЕ, стреляют и рисуют полёт через изменённые функции. Модуль меняет общий для позиции код, поэтому перед слиянием гоняю эти спеки, не весь набор.

## Не входит

- Деривация, угол, высота над морем, Кориолис — T1.3.
- Профиль, произвольный патрон, `CartridgeId` → `string`, прицел в снаряжении — T1.5.
- Имперские подписи калибра и длины — T1.8.

## Как сделано

- Ноль кэшируется **промисом**: раньше одновременные запросы одного патрона (ДОПЕ строит 4 траектории сразу) пристреливали винтовку каждый раз заново. Числа от этого не меняются.
- Снимок регрессии — `src/core/course-dope.regression.json`, снят на `master` (`83c7504`) до правки: сырые траектории (до 0,001 MIL и 0,001 с) и строки ДОПЕ целиком.
- Разброс группы (`analyseGroup`, `groupText`) — параметр. Экраны разбора и итога передают `COURSE_RIFLE.groupSigmaMrad`; в T1.5 — разброс винтовки профиля.
- Попутно: тест дозора «упреждение по ходу цели» ждал знак у упреждения и падал с В43 (`b0cca01`). Переписан под В43: величина та же после разворота, направление хода меняется.

## Мутации

| Мутация | Упавшие тесты |
| --- | --- |
| высота прицела 5,1 см | регрессия траекторий; регрессия ДОПЕ; дуло на высоте прицела (старый) |
| ключ нуля = `cartridge.id` | ноль 200 м ≠ 100 м |
| ключ без совместного нуля | пристрелка один раз |
| кэш после пристрелки, не промис | пристрелка один раз |
| таблица всегда G7 | G1 ≠ G7 |
| холодный ствол и разброс — числа курса | холодный ствол и группа из винтовки снаряжения |
| дуло на −5 см | дуло на высоте прицела снаряжения |
| разброс группы 0,1 всегда | разброс по винтовке снаряжения |
| `courseLoadout` с копией винтовки | учебное снаряжение |
| импорт `RIFLE` в любом файле | `RIFLE` не импортирует ни один файл |
| `movementDirection` всегда 1 | упреждение без стороны, ход меняется (дозор) |
