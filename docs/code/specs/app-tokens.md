# app · токены «прибор и бумага» и одна тема

Статус: реализовано 7.11, слито в `master`. Юнит-тестов 428, e2e 52 (по 26 на mobile-chromium и mobile-webkit) — все зелёные.
Задача бэклога: A1. Решения: Б10 (прибор и бумага), В23 (новый стиль на всех экранах, светлой темы нет), В24 (текст ≥ 13 pt, контраст ≥ 4,5:1, касание ≥ 44, радиус 2 / 6), В25 (шрифты). Источник: [TOKENS.md](../../design/TOKENS.md).

## Зачем

Первая видимая задача. Сейчас в `styles.scss` две темы (A «Полевой HUD» и B «Дневное снаряжение»), цвета `--hub-*` не из TOKENS, радиусы 14–16, градиенты на кнопках, рукописный Caveat. После A1 всё приложение — даже старые экраны до их переписки — в одной палитре прибора, на токенах TOKENS.

## Правила (решено мной)

- **Токены — CSS-переменные в одном файле** `src/theme/_tokens.scss`, имена прямо из TOKENS: `device.bg` → `--device-bg`, `paper.red-pencil` → `--paper-red-pencil`, `type.body` → `--type-body`, плюс отступы, радиусы, тень бумаги, длительности движения.
- **Одна тема.** Тема B, выбор темы в настройках, `settings.theme` и `data-theme` уходят (В23). Старое сохранённое `theme` игнорируется при чтении.
- **Старые экраны не переписываются** в A1 — их переписывают A2–A7. Чтобы они сразу стали «прибором», переменные `--hub-*` становятся **алиасами** токенов (`--hub-bg: var(--device-bg)` …) с пометкой «удалить, когда экран переписан». Ни один новый экран их не использует.

| Старое | Токен |
| --- | --- |
| `--hub-bg` | `--device-bg` |
| `--hub-surface`, `--hub-chip` | `--device-surface`, `--device-surface-2` |
| `--hub-surface-2` | `--device-surface-2` |
| `--hub-text`, `--hub-text-2` | `--device-text`, `--device-text-muted` |
| `--hub-accent`, `--hub-drum-index` | `--device-accent` |
| `--hub-on-accent` | `--device-on-accent` |
| `--hub-ok` | `--device-ok` |
| `--hub-error` | `--device-error-text` (в старых экранах ошибка — текстом) |
| `--hub-warn` | `--device-accent` (в TOKENS нет отдельного «warn»: предупреждение на приборе — латунь) |
| `--hub-line` | `--device-line` |
| `--hub-metal-light`, `--hub-metal-dark` | `--device-line-muted`, `--device-sunken` |
| градиенты кнопок, `--hub-card-shadow` | плоско: `--device-surface-2` / `--device-accent`, без тени (прибор плоский) |

- **Общие классы** `.button`, `.chip`, `.card`, `.label`, `.top-bar`, `.mono` — по TOKENS: радиус 2, рамка 1, без градиентов; главная кнопка — латунь, высота 64 (`.large`), обычная — 48 → **44 минимум** (касание); метки — Roboto Mono 13 капсом с разрядкой 0,07 em; заголовок экрана — Roboto Condensed 700 22 капсом.
- **Шрифты локально**, не с CDN: приложение уходит в Capacitor и должно работать без сети. Пакеты `@fontsource/roboto`, `@fontsource/roboto-condensed`, `@fontsource/roboto-mono` — только нужные начертания (400 / 500 / 700, кириллица + латиница). Caveat и `--font-hand` уходят.
- **Сцена прицела** (`scope-renderer`) — небо одним цветом «поле» (ветка `isDayTheme` уходит). Остальное в сцене — A9.
- **Минимум 13 pt.** В общих классах шрифт меньше 13 не используется. В экранных `.scss` мелкий шрифт поднимают задачи переписки экранов; A1 проверяет только общие классы и токены.

## Юнит-тесты (пишутся до кода)

Логики в A1 мало, но одно проверяется числом — контраст, который TOKENS обещает.

| # | Что проверяем | Пример |
| --- | --- | --- |
| U1 | все токены TOKENS есть в `_tokens.scss` | 15 цветов прибора, 9 бумаги, 7 размеров шрифта |
| U2 | значения совпадают с TOKENS | `--device-accent: #c8a24a` |
| U3 | контраст текста ≥ 4,5:1 (WCAG) | `device.text` на `device.bg-2`, `device.text-muted` на `device.surface`, `device.error-text` на `device.surface`, `paper.ink` / `graphite` / `red-pencil` / `stamp-gold` / `stamp-green` на `paper.bg` |
| U4 | «только крупно» действительно ниже 4,5 | `device.error`, `paper.stamp-silver` — тест фиксирует, что их нельзя пустить в текст (нижняя граница ≥ 3:1 для крупного) |
| U5 | размеры шрифта | нет токена меньше 13 |
| U6 | старые `--hub-*` — только алиасы | в `_legacy-aliases.scss` каждый `--hub-*` = `var(--device-…)` / `var(--paper-…)`, без своих hex |

## Кандидаты на удаление

- `src/theme/_legacy-aliases.scss` (все `--hub-*`) — помечен комментарием в файле и строкой в REMOVAL-CANDIDATES; удалить, когда A2–A7 перепишут экраны (последний — A7).
- Тема B, `ThemeName`, Caveat — удаляются в A1 сразу (замена — одна тема), строка в «Удалено».

## Как сделано

- `src/theme/_tokens.scss` — все токены TOKENS (24 цвета, 7 размеров шрифта, отступы, радиусы, тень бумаги, длительности); `tokens.spec.ts` читает и TOKENS.md, и scss — значения сверяются с документом, а не с копией в тесте.
- `src/theme/_legacy-aliases.scss` — `--hub-*` как ссылки на токены; старые экраны перекрасились без правки их scss.
- Шрифты — `@fontsource` (Roboto 400/500/700, Roboto Condensed 700, Roboto Mono 500/700) через `@use … as …` (Sass не принимает имя модуля «400»).
- `progress.store`: сохранённые настройки читаются по известным ключам — старое `theme` отбрасывается.
- Снимки `docs/design/screens/` пересняты в новой палитре, снимки темы B удалены.
- Найдено по ходу: на хабе чип патрона — 42 px (стиль экрана `hub.page.scss`), меньше нормы касания 44. Экран переписывается в A2 — там и исправится; e2e касания меряет экраны без своих переопределений (настройки, ДОПЕ).
