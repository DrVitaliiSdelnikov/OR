# app · английский язык (T6.3)

Статус: реализовано 22.11 — этап 1 (`feat/english-shell`, `08332cc`), этап 2 (`feat/english-course`). Решения автора 22.11 (В61): RU + EN; при первом запуске — по системе, переключатель в настройках; два этапа. Логика — решено мной.
Задача бэклога: T6.3. Решения: В38, В40, В61. Перед: ребрендинг (app-rebrand).

## Правила

- **Каталоги:** `src/i18n/ru` и `src/i18n/en` одного типа `Messages`. Тест сверяет форму: ключи, функции, длины списков.
- **Язык выбирается до загрузки каталога** (`i18n/index.ts`): сохранённый выбор (`localStorage` `or.language`) → иначе система: `ru`, `uk`, `be`, `kk` → русский, остальное → английский → по умолчанию русский.
- **Автовыбор английского по системе включается, только когда английский полный** (`PENDING_EN_MODULES` пуст). До этого английский — только явным выбором: иначе англоязычный пользователь увидел бы смесь.
- **Смена языка:** настройки → «Язык» (Русский / English, у English пометка «частично», пока перевод не полный) → выбор сохраняется, приложение перезагружается.
- **Форматы по языку** (`format.ts`, `useNumberFormat`): дробь — запятая / точка; процент — «85 %» / «85%»; множественное — русские три формы / английские one-other; список — «и» / «and».
- **Единицы в английском** — сокращения без склонения: m, yd, m/s, mph, °C, °F, hPa, inHg, g, gr, mm, in, ft, cm.
- `<html lang>` и заголовок вкладки ставятся при запуске.
- **Название:** «Sniping Simulator» (В61); курс — «Sniper course»; САМ / АВТО → MANUAL / AUTO; ДОПЕ → DOPE; ВЕРТ → ELEV; ДЕР → SPIN.

### Этапы

1. Инфраструктура и экраны: главный, настройки, дрилы, задание дня, прогресс, винтовка, журнал, «О приложении», «Модель», листы итога и разбора, свой дрил.
2. Курс и учебник: `content`, `instructor`, `intro`, `notebook`, `position`, `radio`, `result`, `briefing`, `review`, `textbook`; e2e упражнения 01 на английском; включение автовыбора по системе.

## Как сделано (этап 1)

- `i18n/language.ts`: `initialLanguage(stored, systemLanguages, isEnglishComplete)`, `storedLanguage`, `saveLanguage`, `systemLanguages`.
- `i18n/en/*`: переведены `about`, `daily`, `drills`, `skills`, `screens`, `shell`, `units`, `model`, `rifle`, `app-name`; модули этапа 2 пока берутся из русского (`PENDING_EN_MODULES`).
- `i18n/index.ts`: `language`, `isEnglishComplete`, `text = CATALOGS[language]`, `useNumberFormat(language)`.
- Настройки: раздел «Язык» (`language-ru`, `language-en`); `App` ставит `lang`; `index.html` — `lang="ru"`.
- Тесты каталога (`en/catalog.spec.ts`): форма как у русского; список ожидания равен модулям, взятым из русского; нет кириллицы, кроме «Русский»; дроби и единицы только через форматтеры.

## Как сделано (этап 2)

- Словарь и правила — [app-english-glossary.md](app-english-glossary.md): термин учебника — идентификатор, на него по строке ссылаются `related`, `termLinks`, песочницы, схемы, `content.exerciseTerms`, подсказки тренера.
- Переведены `content`, `instructor`, `intro`, `notebook`, `position`, `radio`, `result` / `briefing`, `review`, `textbook` (параллельно тремя агентами по словарю; сверено: вкладки блокнота TOTAL / DISTANCE / CONDITIONS / WIND / DOPE одинаковы в блокноте, учебнике и подсказках).
- `PENDING_EN_MODULES` пуст → автовыбор английского по системе включён.
- Тип главы учебника — `string` (был союз русских строк); принадлежность главы проверяют тесты обоих языков.
- Дата задания дня — из каталога (`daily.shortDate`): ДД.ММ / ММ/ДД.
- Юнит-тесты закреплены на русском языке системы: `src/test-setup/russian-system-language.ts` в `vitest.core.config.ts`, новом `vitest.config.ts` (запуск без `--config`) и `angular.json` (`ng test`). Иначе Node и jsdom с `navigator.languages = ['en-US']` включали бы английский.
- e2e-помощник `clicksToTarget` читает число из счётчика барабана без русского «ещё».
- «В планах» «О приложении»: пункт про английский убран.

## Отступления

- Буквы формул в английском выбраны агентами: клик `N = C / V`, условия `C` и `Pc`, Этвёш `Ev`, Кориолис `K` (совпадает с константой ветра — как в русском). Позывной вводного «Старший» → «Range officer».

## Только английский (В62, 22.11)

Решение автора: игроку — только английский, выбора нет.

- `i18n/language.ts`: `APP_LANGUAGE = 'en'`, `activeLanguage(testLanguage)` — английский, если тесты не подставили язык; `initialLanguage`, `storedLanguage`, `saveLanguage`, `systemLanguages` — `@deprecated` (REMOVAL-CANDIDATES).
- `i18n/index.ts`: язык — `activeLanguage(globalThis.__orTestLanguage)`. Крючок ставят только тесты: юнит — `src/test-setup/russian-test-language.ts` (в `vitest.config.ts`, `vitest.core.config.ts`, `angular.json`), e2e — `seedProgress` через `useTestLanguage(page, 'ru')`; `english-course` ставит `'en'`, `language` — снимает крючок.
- Настройки: раздел «Язык» убран; тексты `settings.language`, `languages`, `englishPartial` убраны из обоих каталогов. `index.html` — `lang="en"`.
- Русский каталог остаётся: на нём весь набор тестов и сторож лексики.

| Тест | Мутация → красный |
| --- | --- |
| `language.spec` | язык по умолчанию — русский; крючок игнорируется |
| e2e `language` | `activeLanguage` снова читает сохранённый выбор; язык по умолчанию — русский |
