# app · английский язык (T6.3)

Статус: этап 1 реализован 22.11, ветка `feat/english-shell`; этап 2 — впереди. Решения автора 22.11 (В61): RU + EN; при первом запуске — по системе, переключатель в настройках; два этапа. Логика — решено мной.
Задача бэклога: T6.3. Решения: В38, В40, В61. Перед: ребрендинг (app-rebrand).

## Правила

- **Каталоги:** `src/i18n/ru` и `src/i18n/en` одного типа `Messages`. Тест сверяет форму: ключи, функции, длины списков.
- **Язык выбирается до загрузки каталога** (`i18n/index.ts`): сохранённый выбор (`localStorage` `or.language`) → иначе система: `ru`, `uk`, `be`, `kk` → русский, остальное → английский → по умолчанию русский.
- **Автовыбор английского по системе включается, только когда английский полный** (`PENDING_EN_MODULES` пуст). До этого английский — только явным выбором: иначе англоязычный пользователь увидел бы смесь.
- **Смена языка:** настройки → «Язык» (Русский / English, у English пометка «частично», пока перевод не полный) → выбор сохраняется, приложение перезагружается.
- **Форматы по языку** (`format.ts`, `useNumberFormat`): дробь — запятая / точка; процент — «85 %» / «85%»; множественное — русские три формы / английские one-other; список — «и» / «and».
- **Единицы в английском** — сокращения без склонения: m, yd, m/s, mph, °C, °F, hPa, inHg, g, gr, mm, in, ft, cm.
- `<html lang>` и заголовок вкладки ставятся при запуске.
- **Название:** «Sniping Simulator» (В61); курс — «Sniper course»; САМ / АВТО → MANUAL / AUTO; ДОПЕ → DOPE; ВЕРТ → ELEV; ДЕР → SPIN.

### Этапы

1. Инфраструктура и экраны: главный, настройки, дрилы, задание дня, прогресс, винтовка, журнал, «О приложении», «Модель», листы итога и разбора, свой дрил.
2. Курс и учебник: `content`, `instructor`, `intro`, `notebook`, `position`, `radio`, `result`, `briefing`, `review`, `textbook`; e2e упражнения 01 на английском; включение автовыбора по системе.

## Как сделано (этап 1)

- `i18n/language.ts`: `initialLanguage(stored, systemLanguages, isEnglishComplete)`, `storedLanguage`, `saveLanguage`, `systemLanguages`.
- `i18n/en/*`: переведены `about`, `daily`, `drills`, `skills`, `screens`, `shell`, `units`, `model`, `rifle`, `app-name`; модули этапа 2 пока берутся из русского (`PENDING_EN_MODULES`).
- `i18n/index.ts`: `language`, `isEnglishComplete`, `text = CATALOGS[language]`, `useNumberFormat(language)`.
- Настройки: раздел «Язык» (`language-ru`, `language-en`); `App` ставит `lang`; `index.html` — `lang="ru"`.
- Тесты каталога (`en/catalog.spec.ts`): форма как у русского; список ожидания равен модулям, взятым из русского; нет кириллицы, кроме «Русский»; дроби и единицы только через форматтеры.

## Отступления

- Дата в «Поделиться» задания дня (`shortDate`, ДД.ММ) не зависит от языка — в этапе 2.
- В английских «В планах» пункт «Full English translation» — уберётся в этапе 2 вместе с русским «Английский язык».
