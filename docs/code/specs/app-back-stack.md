# app · «назад» и выход (A8)

Статус: одобрено 11.11. **Реализовано 12.11, слито в `master`.** Юнит-тестов 778 (новых 6: U1–U5). e2e `e2e/back-stack.spec.ts` — 11 сценариев (E1–E10 и E1b), по 11 на mobile-chromium и mobile-webkit. Мутаций — см. «Мутации».

Отличие от плана: в E10 термин открыт не на главном (там нет ссылок на термины), а в учебнике — проверяется то же правило «слой раньше страницы». Выстрел в e2e — «спуск тапом» из настроек. Добавлен E1b: без него обработчик страницы позиции не проверялся — история с проверкой ухода давала тот же итог везде, кроме песочницы учебника. Перед первой системной «назад» тест ждёт, пока `ion-app` начнёт слушать `backbutton` (подключается ленивым импортом): пробное событие перехватывает собственный обработчик теста с приоритетом 1000, приложение его не видит.
Задача бэклога: A8. Решения: В15 (слои по очереди, подтверждение выхода, «прервано», «назад» — туда, откуда пришли), Б12. Бриф [01](../../design/briefs/01-shooter.md) («Системная «назад» закрывает слои по очереди»). Связано: [app-position](app-position.md) (подтверждение «Покинуть позицию?»), [app-journal](app-journal.md) («прервано»), [app-main-course](app-main-course.md) (на главном — выход из приложения).

Уже есть:
- `←` позиции (`back()`): закрывает шторку блокнота; после выстрела показывает подтверждение «Покинуть позицию? Упражнение не засчитается»; в свободной игре и после конца серии уходит сразу. Уход пишет серию в журнал, без итога — «прервано»;
- шапки других экранов: `←` — `routerLink` на жёстко заданного родителя (журнал → `/`, лист упражнения → `/course` и т. д.), даже если игрок пришёл с другого экрана;
- системная «назад» (Android, жест браузера) **не перехватывается**. Ionic по ней снимает страницу со своего стека, открытые слои не закрываются, подтверждения нет: игрок теряет серию одним жестом;
- Ionic слушает системную «назад» только в гибридной сборке (`hardwareBackButton`), плагина `@capacitor/app` нет — на телефоне её получает WebView;
- серия пишется в журнал при листе итога, при «пересчитать и повторить», при уходе и при уничтожении страницы. Если приложение свернули и убили, серия теряется: в журнале её нет вовсе;
- журнал только добавляет серии (`withSeries`), не заменяет по `id`.

## Зачем

Системная «назад» — самый частый жест на Android. Сейчас она выкидывает с позиции посреди серии, мимо подтверждения, и не закрывает шторки. По В15 «назад» снимает по одному слою, выход с позиции после выстрела — через подтверждение, а брошенная серия остаётся в журнале «прервано».

## Правила

### Слои

**Слой** — то, что лежит поверх экрана и закрывается без перехода: лист термина, подтверждение, шторка блокнота, шаг расчёта, формулы, разбор выстрела, лупа барабана, подтверждение сброса. Слои кладутся в общий стек в порядке открытия. «Назад» закрывает **верхний** слой и больше ничего не делает.

| Экран | Слои сверху вниз (что закрывает «назад») |
| --- | --- |
| любой | лист термина (поверх всего) |
| позиция | подтверждение выхода («Остаться») → лупа барабана → формулы → шаг расчёта («← к итогу») → шторка блокнота → разбор выстрела |
| настройки | подтверждение сброса («Отмена») |

Лист итога не слой: «назад» с него — уход с позиции, как сейчас `←`.

### Когда слоёв нет

| Экран | «Назад» |
| --- | --- |
| позиция | то же, что `←`: до первого выстрела, в свободной игре, после конца серии — уход; иначе — подтверждение |
| главный | первое «назад» — подсказка внизу «Нажмите ещё раз, чтобы выйти» на 2 с; второе за эти 2 с — выход из приложения (на телефоне; в браузере подсказка есть, выхода нет) |
| остальные | туда, откуда пришли |

**«Туда, откуда пришли»** — предыдущая страница стека Ionic; если её нет (открыли по ссылке, перезагрузили) — родитель экрана: лист упражнения → тропа, тропа / журнал / учебник / настройки / свободная → главный, вводное → лист 00. Экранная `←` в шапке делает то же самое, что системная: журнал, открытый с листа итога, возвращает на лист итога.

### Источники «назад»

- **Android** — `@capacitor/app` (новая зависимость) передаёт системную кнопку в Ionic; Ionic включаю всегда (`hardwareBackButton: true`), чтобы в браузере работало то же событие и e2e могли его вызвать. Выход — `App.exitApp()`.
- **Браузер** (жест или кнопка «назад» истории) — переход с позиции проходит через проверку ухода: если нужно подтверждение, переход отменяется, URL остаётся `/position/…`, показывается подтверждение. Слои по истории браузера не закрываются: это стек приложения, а не адресная строка.

### «Прервано» при сворачивании

- Приложение ушло в фон (`visibilitychange` → `hidden`, на телефоне — пауза Capacitor) с серией, где уже был выстрел, — серия пишется в журнал «прервано» сразу: если систему убьёт приложение, запись останется.
- Вернулись и доиграли — та же серия (тот же `id`) **заменяет** запись: в журнале одна строка с классом, а не две. Журнал заменяет серию с тем же `id` на месте, а не добавляет новую.
- Убили приложение — при следующем запуске главный экран, упражнение заново (В15), в журнале «прервано».
- Песочница учебника журнал не пишет, как сейчас.

## Граничные случаи

- Два слоя открыты (разбор и поверх него лист термина) — первое «назад» закрывает термин, второе — разбор, третье — подтверждение выхода.
- Слой закрылся сам (лупа по таймеру, шторка кнопкой) — он уходит из стека; «назад» не тратится на уже закрытый слой.
- Подтверждение открыто, жмут «назад» — подтверждение закрывается («Остаться»), игрок на позиции. Второй «назад» — снова подтверждение, не уход.
- Уход после подтверждения не спрашивает второй раз (проверка ухода пропускает подтверждённый выход).
- Ушли в фон до первого выстрела — ничего не пишется (пустая серия не пишется, как сейчас).
- Ушли в фон дважды — одна запись, обновлённая.
- Свободная игра: в фоне пишется как есть, без «прервано» (у неё нет конца серии), при возврате запись дополняется.
- Главный экран с открытым листом термина — «назад» закрывает термин, не выходит.
- Вводное: «назад» — лист 00, как `←` (прогресс шагов не пишется, как сейчас).
