# i18n — каталог текстов с параметрами

Статус: одобрено 13.11. **A10a и A10b реализованы 13.11, слиты в `master`** (итоги — в «как сделано»). Вне `src/i18n/` русского текста нет.
Задача бэклога: A10. Решения: В7 («все числа в текстах подставляются из расчёта»). Автор 13.11: язык пока один — русский; английский, вероятно, будет позже.

## Зачем

- Сейчас тексты лежат прямо в коде: около 1100 строк в 65 файлах, из них 455 в учебнике.
- Около 20 текстов содержат числа, вписанные руками. Если поменять константу в расчёте, текст начнёт врать: «Держи «Замер» 3 с», «Формулы −30», «≥ 70 % очков», «10 · первым», «от 3 выстрелов», «флажки на 200, 400, 600 м».
- Дробные числа форматируются в десяти местах по-разному: где-то `replace('.', ',')`, где-то через точку («0.87», «3.44 MOA»).
- Нужен один каталог, к которому английский добавляется одним файлом без правки экранов.

## Публичный интерфейс

Папка `src/i18n/` — лист зависимостей: ничего не импортирует из `app`, `sim`, `core`. Её можно импортировать отовсюду, в том числе из `sim` и `core`.

| Файл | Что |
| --- | --- |
| `format.ts` | `decimal(value, digits)` — дробная часть через запятую; `signed(value, digits)` — «+0,3» и «−0,3» (минус U+2212); `percent(share)` — «70 %»; `plural(count, forms)` — русские формы для 1, 2–4 и 5+, включая 11–14 |
| `ru/<область>.ts` | Тексты одной области: `home`, `course`, `briefing`, `position`, `notebook`, `review`, `result`, `instructor`, `intro`, `textbook`, `journal`, `free`, `settings`, `content` (винтовка, патроны, прицелы, названия и цели упражнений) |
| `ru/index.ts` | `ru` — объект из всех областей |
| `messages.ts` | `type Messages = typeof ru`; будущий `en` обязан иметь ту же форму и те же параметры, иначе не соберётся |
| `index.ts` | `text: Messages` — текущий язык (пока всегда `ru`) |

Как выглядит текст:
- Без чисел — строка: `title: 'Настройки'`.
- С числами — функция с именованными параметрами. Числа она получает сырыми и форматирует через `format.ts`, потому что формат числа — дело языка:
  `measureHold: (p: { seconds: number }) => \`Держи «Замер» ${p.seconds} с\``.
- По ключу id — `Record<ExerciseId, …>`, `Record<CauseKind, …>` и т. п. Полноту ключей проверяет TypeScript.

Как читают:
- Модель или функция: `text.position.flagReading({...})`.
- Шаблон: компонент держит `protected readonly text = text.settings`, в шаблоне `{{ text.title }}`.
- `sim` и `core` берут названия, описания и цели из `text.content` по id. Их интерфейс (`ExerciseDef.title`, `Cartridge.name`…) не меняется, поэтому экраны правок не требуют.

Язык выбирается один раз при старте. Будущий переключатель в настройках сохранит язык и перезагрузит приложение. Сигналов и пайпов перевода не будет: тексты не меняются, пока приложение запущено.

## Правила

1. **Ни одной кириллической строки вне `src/i18n/`**, кроме `*.spec.ts`, комментариев и `data-test`. Это проверяет страж-тест (ю1).
2. **Число, у которого в коде есть источник, берётся из источника.** Источник — константа, задание упражнения или расчёт. Исключение — определения, они не зависят от настроек игры: «1 клик = 0,1 MIL», формула «Д = размер × 1000 / MIL», «12 — от цели в лицо». Такие числа остаются в тексте.
3. **Дублированная константа сводится к одной.** Подпись берёт её же:
   - время полного замера: сейчас три копии — `conditions-tab` (3000 мс), `position-session` и `sim/notebook`; остаётся одна в `sim/notebook`;
   - доли классов и очки за выстрел: копии в `result.model`; остаются экспорты `core/exercise-scoring`.
4. **Дроби — через `decimal`.** Ни одного `replace('.', ',')` вне `format.ts`.
5. **Видимый текст не меняется**, кроме трёх исправлений: «0.5» → «0,5», «0.87» → «0,87» в долях часов и «3.44 MOA» → «3,44 MOA». Поэтому e2e не правятся, они сами проверяют, что перенос ничего не сломал.

## Граничные случаи

- `plural`: 0, 1, 2, 4, 5, 11, 12, 14, 21, 22, 25, 111 — «0 выстрелов», «1 выстрел», «2 выстрела», «5 выстрелов», «11 выстрелов», «21 выстрел», «22 выстрела».
- `decimal` у отрицательного и у −0: «−0,3»; −0 → «0,0», без минуса.
- `decimal` округляет как сейчас `toFixed`, чтобы ни одно число на экране не сдвинулось.
- В `data-test`, `aria-label` и `title` тоже текст. `data-test` — латиница, в каталог не идёт. `aria-label` и `title` переносятся в каталог.
- Текст с разметкой внутри (жирное в учебнике, `<b>` в справочнике) делится на части каталога. Шаблон собирает части сам, `innerHTML` не используется.

## Пользовательские тесты

Новых сценариев нет. Переносом затронут каждый экран, поэтому перед слиянием каждого коммита — **полный прогон** `npm run test:e2e:build` на обоих телефонах (правило README «общее для всех экранов»).

Отдельно проверю e2e, где встречаются исправленные дроби: справочник формул (доли часов, «1 MIL = 3,44 MOA»). Если тест ждёт точку, он кодирует ошибку и правится вместе с ней.
