# app · экран «Прогресс» (T4.3)

Статус: реализовано 21.11, ветка `feat/progress`. Продуктовые решения — автор 21.11: на графике общий уровень; на главном плитка «Прогресс» вместо журнала и уровень вместо звания; названия уровней T4.1 остаются.
Задача бэклога: T4.3. Решения: В39 (рейтинг навыков вместо званий). Перед: T4.1, T4.2, T3.5.

## Зачем

Игрок видит, где он сейчас и растёт ли: общий уровень, навыки по рейтингу, ход уровня по неделям и частые ошибки. Журнал открывается отсюда.

## Правила

### Экран `/progress`

1. **Уровень** — «Стрелок · 58» (название по порогам T4.1, среднее рейтингов навыков с попытками, округлено). Без попыток — «Уровень не определён» и подсказка «пройди дрил или упражнение».
2. **Навыки** — 8 строк в порядке навыков: название, рейтинг (округлён), полоска 0–100, число попыток. Навык без попыток — рейтинг приглушён, «нет попыток».
3. **По неделям** — общий уровень на конец каждой из последних 8 недель (неделя с понедельника 00:00 UTC). Текущая неделя — по сохранённому рейтингу, чтобы точка совпадала с уровнем в шапке. Прошлые недели не хранятся: журнал и раунды дрилов пересчитываются до конца недели тем же порядком, что и T4.2. Неделя, к концу которой попыток не было, — без точки. Подписи — дата понедельника «16.11».
4. **Ошибки по типам** — за 4 недели: типы проверки расчёта из выстрелов журнала и карточек дрилов, по убыванию; при равенстве — по порядку типов проверки (как у тренера). Нет ошибок — «ошибок проверки нет».
5. **Журнал** — кнопка «Журнал стрелка» → `/journal`; «назад» из журнала — на «Прогресс».

### Главный экран

- Плитка «05 Журнал стрелка» → «05 Прогресс» (`/progress`).
- Шапка: вместо звания — уровень («Стрелок · 58» / «Уровень не определён»), допуски остаются. `rankHeader` на главном больше не нужен; тропа и достижения журнала со званием пока остаются (REMOVAL-CANDIDATES, строка званий).

## Готово, когда

- Юнит: строки навыков; уровень и «не определён»; недели — границы, пересчёт до конца недели, пустые недели, подписи; ошибки — окно 4 недели, оба источника, порядок и равенство.
- e2e: главная → «Прогресс»: уровень, 8 навыков, график, ошибки, «Журнал стрелка» → журнал → «назад» → «Прогресс»; шапка главного с уровнем.
- Мутации на каждый новый тест.

## Как сделано

- `app/progress/progress.model.ts`: `levelView`, `skillRows`, `weeklyLevels(journal, rounds, nowIso, currentRatings)` (прошлые недели — `replayedLedger` по записям до конца недели, текущая — `currentRatings`), `errorTypeRows` (порядок при равенстве — `ERROR_TYPE_ORDER` тренера, теперь экспортирован из `sim/coach.ts`).
- `progress.page.ts`, маршрут `/progress`: уровень, SVG-линия по неделям с сеткой 25 / 50 / 75 и подписями, 8 карточек навыков с полоской, ошибки, кнопка «Журнал стрелка». Тексты — `i18n/ru/skills.ts` (`progress`).
- Главный: плитка «05 Прогресс», в шапке `levelView` вместо звания (`data-test="level"`); `rankHeader` остаётся для допусков и тропы. «Назад» из журнала — `/progress`.
- Брифы: 08 (меню, шапка), новый 17 «Прогресс».

## Отступления от спеки

- Текущая неделя по сохранённому рейтингу (найдено при проверке в Chrome): на реальном прогрессе пересчёт давал 40 при уровне 38 в шапке — рейтинг Эло зависит от порядка попыток, а сохранённый рейтинг набирался по ходу игры. Прошлые недели остаются пересчётом и могут отличаться от тогдашнего сохранённого значения на единицы.
