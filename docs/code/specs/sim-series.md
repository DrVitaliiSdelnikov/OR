## Правила (решено мной, Б31, Б33)

- **Патронов в упражнении** = целей × выстрелов на цель (по FM 23-10 — 2). Упр. 02 — одна мишень и 5 выстрелов, правило «2 на цель» не действует.
- **Цель закрыта**, когда попал или кончились выстрелы на неё. Следующий выстрел — по следующей цели.
- **Упражнение закончено**, когда закрыты все цели. Патроны, что остались после попаданий первым, не нужны: это и есть «на 0» из Б31 — патронов на открытые цели больше нет.
- **Магазин** — 5. Заряжается min(5, патронов осталось), первый досылается в патронник. Пусто, а упражнение не закончено → «сменить магазин» тем же патроном.
- **Этапы.** Упражнение — список этапов «патрон · цели · выстрелов на цель». Обычно этап один; в упр. 08 их три (А, Б, В по 2 выстрела по одному гонгу). Новый этап — всегда новый магазин.
- **Свободная игра:** патронов без счёта, цель одна. Магазин пуст → «сменить магазин». Сменить магазин или патрон можно между выстрелами в любой момент: начинается новая серия, очки прошлых сохраняются, недострелянный магазин в счёт не идёт.

## Холодный выстрел (S7)

- Холодный — первый выстрел упражнения и первый выстрел сессии свободной игры. Смена магазина и этапа ствол не охлаждает.
- В курсе действует с упр. 02, где о нём рассказывают; в упр. 01 его нет.
- Сдвиг — постоянное свойство винтовки, а не случайность: `RIFLE.coldBoreShiftMil` = ↑ 0,15, → 0,05 MIL (≈ 1,5 см на 100 м, в пределах обычных 0,5–1 MOA). Постоянство и есть суть: зная сдвиг своей винтовки, снайпер держит под него.
- В `resolveShot` сдвиг прибавляется к попаданию отдельным слагаемым `coldBore` (у тёплого выстрела — 0, 0).
- В разборе это серый лепесток «холодный ствол», не ошибка игрока (A6).
- Поправка на второй выстрел и запись в ДОПЕ считаются без сдвига: ствол уже тёплый, и барабан под холодный выстрел крутить нельзя. Поэтому `secondShotCorrection` и `dopeNoteElevationMil` получают попадание за вычетом `coldBore`.
- Группа (`analyseGroup`) строится без холодного выстрела — в журнале он записывается отдельно (FM 23-10).

## sim/firing-line.ts (S6)

```ts
interface FiringStage { cartridgeId: CartridgeId; targetCount: number; maxShotsPerTarget: number; closesOnHit: boolean }
type FiringPlan = { kind: 'exercise'; stages: FiringStage[]; hasColdBore: boolean } | { kind: 'free'; cartridgeId: CartridgeId }
```

| Метод / поле | Что делает |
| --- | --- |
| `new FiringLine(plan)` | первый этап, первая цель, магазин заряжен |
| `cartridgeId`, `stageIndex`, `targetIndex` | что сейчас стреляем и по какой цели |
| `magazineLoaded`, `magazineLeft` | для счётчика «4 / 5»: сколько зарядили в магазин и сколько осталось вместе с патронником |
| `isNextShotCold` | следующий выстрел холодный (S7) |
| `recordShot(isHit)` | записывает выстрел в текущую цель, закрывает цель, двигает этап; возвращает события `FiringEvent[]`: `'target-closed'`, `'next-target'`, `'magazine-empty'`, `'stage-done'`, `'exercise-done'` |
| `changeMagazine(cartridgeId?)` | новый магазин; в упражнении — только когда пуст или этап сменился, патрон — из этапа; в свободной игре — когда угодно и любым патроном, начинает новую серию |
| `series` | серии: патрон, выстрелы `{ isHit, isColdBore }` по целям — вход для `targetPoints` и журнала |
| `isFinished` | упражнение закончено |

`BoltAction.insertMagazine(rounds = 5)` получает число патронов — сейчас всегда 5. Остальной затвор не меняется: `FiringLine` решает, сколько зарядить, затвор — как досылать.

## Граничные случаи

- Попадание первым по последней цели — `exercise-done`, даже если патроны остались.
- Упр. 02 (1 цель, 5 выстрелов): цель не закрывается попаданием — все 5 выстрелов по одной мишени (пристрелка, группа). Этап: `maxShotsPerTarget: 5`, `closesOnHit: false`; очки упр. 02 считаются не по `targetPoints`, а по навыковым целям (S8).
- 10 целей × 2 = 20 патронов: магазин меняется, пока упражнение не кончится; цель не закрывается сменой магазина.
- `recordShot` после `exercise-done` — ошибка (`RangeError`), как в `targetPoints`.
- В упражнении `changeMagazine` при непустом магазине того же этапа — ошибка: курс не даёт сменить магазин, пока патроны есть (Б33).
- Свободная игра: `changeMagazine('C')` после двух выстрелов — новая серия патроном В, две записи прошлой сохранены, ствол не холодный.

## Пользовательские тесты

Видимых изменений нет: секция стрелка переходит на `FiringLine` в A3, разбор — на лепесток «холодный ствол» в A6. Прежние 46 e2e должны остаться зелёными на обоих телефонах.

## Кандидаты на удаление

Строки в [REMOVAL-CANDIDATES](../REMOVAL-CANDIDATES.md):
- `GameSession.shotsLeft` — помечен `@deprecated`, удаляется в A3;
- начальное заряжание `ScopeSession.bolt` 4 + 1 — меняется в A3 на `FiringLine.magazineLoaded`; само поле `bolt` живое, поэтому в коде не помечено.

## Как сделано

- `resolveShot(…, { isColdBore: true })` — новое поле `ShotResult.coldBore`; сдвиг входит и в попадание, и в шанс попадания (иначе холодный сдвиг ушёл бы в «везение»).
- `warmImpact(impact, coldBore)` в `sim/shot-review` — попадание без холодного сдвига для поправки на второй выстрел и записи в ДОПЕ.
- Конец этапа разряжает магазин: остаток прошлого патрона не стреляется, новый этап — `changeMagazine()` с патроном этапа.
- Свободная игра: одна цель, выстрелы без ограничения; смена нетронутого магазина пустую серию не оставляет.
