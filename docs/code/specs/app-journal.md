## Зачем

Где я стабильно ошибаюсь и почему (Б8). Блокнот — для стрельбы, журнал — архив и разбор.

## Запись серий

**Серия** — один заход на позицию: упражнение или свободная игра.

```
JournalSeries { id, startedAtIso, kind: 'exercise' | 'free', exerciseId?, title, mode, cartridgeIds, distanceText,
                exerciseClass?, total?, isInterrupted, isTapTrigger, shots: JournalShot[] }
JournalShot   { distanceM, isHit, isFirstAtTarget, impact, call, diagnosis, mainCause, errorTypes, windSpeedMps, mode }
```

- Пишется, **когда серия кончилась** (лист итога) или **игрок ушёл с позиции после выстрела** — тогда «прервано» (В15). Свободная игра — всегда при выходе.
- Без выстрелов — ничего не пишется.
- **Хранится последние 200 серий**; старые уходят. Статистика и ошибки считаются по тому, что есть.
- **Старый `ShotRecord` и `shots` удаляются** (В31): их никто не пишет, старые сохранения с ними читаются без них.

## Как сделано

- **Серия** собирается `journalSeries` из задания позиции, записей выстрелов и итога; первый выстрел по цели — по паре этап/цель. Ветер у стрелка в момент выстрела — новое поле `ExerciseShotRecord.windSpeedMps`.
- **Когда пишется** — при листе итога, при «пересчитать и повторить» (прежняя попытка — «прервано») и при уходе с позиции. Ionic держит страницу в стеке и не уничтожает её при переходе вперёд, поэтому уход пишется явно в `leave()`; уничтожение страницы — запасной путь. Одна сессия пишется один раз.
- **Хранилище** — `ProgressStore.journal` (последние 200), `addSeries`; старый `shots` из сохранения не читается.
- **Карточки** — заводские строки строятся движком при открытии журнала (как в позиции, клик 0,1 MIL), записи игрока — из `dopeNotes`.
- **Штамп** — цвет по классу, как на листе итога (красный, золото, серебро, бронза), «прервано» — графитом.
- **Проверено в Chrome**: 01 до итога → «В ЖУРНАЛ» → лента, раскрытая серия, ошибки, карточки, достижения; пустой журнал со старым сохранением.

## Отступления от черновика

- **Свободная игра не бывает «прервано»** — у неё нет конца серии.
- **Тап по выстрелу открывает строку причины**, а не полный разбор — как и записано в «Не входит».
