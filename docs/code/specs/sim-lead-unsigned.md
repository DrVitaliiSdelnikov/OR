# sim · упреждение без стороны

Статус: реализовано 15.11, ветка `feat/lead-unsigned`. Новых юнит-тестов 9, e2e 1 (на двух движках); мутация на каждый. `core/calc-check.ts` не менялся: шаг упреждения приходит в проверку без знака, `side` не возникает. Таблица проверки показывает упреждение без стрелки.
Задача бэклога: T0.4 (находки прохождения 11). Решение: В43. Связано: [sim-patrol](sim-patrol.md), [sim-notebook](sim-notebook.md), [sim-shot-review](sim-shot-review.md), [core-scoring-and-check](core-scoring-and-check.md).

## Зачем

Прохождение 11 (15.11) нашло четыре связанных дефекта:

| Что видно | Почему |
| --- | --- |
| попадание, но проверка расчёта — «ОШИБКА · СТОРОНА», +0 за расчёт; 2 класс недостижим | шаг «Упреждение» хранит знак на момент расчёта, проверка сравнивает его со знаком на момент выстрела; цель развернулась |
| плитка «УДЕРЖ.» показывает «← 0,9 L», а цель идёт вправо | плитка берёт знак из записанного шага |
| на попадании «Сетка ушла вправо на 2,1 — ошибка выполнения» | `diagnoseShot` меряет сетку от центра цели; вынесенное упреждение считается промахом руки |
| итог «11 из 12 — упреждение» при верных расчётах | следствие предыдущего: главная ошибка берётся из тех же разборов |

## Правила (В43)

- **Шаг «Упреждение» считает только величину.** Формула и лента те же (L = V⊥ цели × t / D × 1000, три строки), кнопок ←/→ нет. Единицы MIL/MOA остаются.
- **Проверка шага — по модулю.** `side` для шага упреждения не бывает; остальные типы (`lead`, `units`) как сейчас.
- **Сторону берёт стрелок в прицеле** — по ходу цели в момент выстрела. Это и есть подсказка «держи сеткой впереди цели».
- **Плитка «УДЕРЖ.»** — горизонталь = удержание по ветру + L со знаком текущего хода цели. На развороте стрелка меняется.
- **Диагноз выстрела** меряет сетку не от центра цели, а от точки, куда стрелок должен был держать: план удержания + L по текущему ходу. Верно вынесенное упреждение → «чисто» / «данные».
- **«Упреждение назад»** — ошибка стороны теперь у выстрела: сетка в момент выстрела вынесена против хода цели дальше допуска сетки (0,2 MIL) от плана удержания, при L ≥ 1 клика. Разбор: «Упреждение назад: сетка позади цели — выноси по ходу».
- **2 класс 11:** «≥ 7 из 10 и ни разу упреждение назад» вместо «ни одной ошибки СТОРОНА». 09 не трогаем: там СТОРОНА — про ветер.
- **Авто-режим и свободная игра:** фактор «Упреждение» тоже без знака; сторону даёт текущий ход цели.
- **Журнал:** старые записи с `side` на шаге упреждения не переписываем.
