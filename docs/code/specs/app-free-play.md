Задача бэклога: A7.1 (A7 делится: 7.1 свободная игра, 7.2 журнал, 7.3 учебник, 7.4 настройки, 7.5 упр. 00). Решения: В9, Б33, В15, В30. Бриф [09](../../design/briefs/09-free-play.md). Логика: [COURSE](../../logic/COURSE.md) — что когда открывается, [SCOPES](../../logic/SCOPES.md) — каталог прицелов.

Уже есть:
- `courseProgress(...).freePlayUnlocks` — что открыто в свободной игре: неизвестная дистанция, САМ лёгкий / сложный, патроны А и В, порывистый ветер, прицелы;
- `FiringLine` с планом `{ kind: 'free' }` — бесконечная серия одним патроном, смена магазина;

- плитка «02 · Свободная игра» на главном — пока «откроется позже».

## Зачем

Курс ведёт за руку. Свободная игра — стрельба без оценки: игрок сам выбирает дистанцию, ветер, прицел, патрон и режим блокнота и тренирует то, что не даётся.

## Экран настроек `/free` (бриф 09)

| Блок | Как |
| --- | --- |
| Шапка | «назад», «СВОБОДНАЯ ИГРА», «параметры выстрела» |
| Дистанция | крупно «600 м», ползунок 100–1000 м шагом 50, тик на каждом шаге (A4, `detent`). Переключатель «неизвестная» — дистанция случайная из 100–1000, мерить сеткой |
| Ветер | плитки: штиль · слабый · умеренный · сильный · порывистый |
| Прицел и патрон | две плитки; тап — лист выбора: прицелы из `SCOPES` с одной строкой (сетка, кратность), патроны А / Б / В с одной строкой (масса, скорость, BC) |
| Режим блокнота | АВТО · САМ лёгкий · САМ сложный, с множителем |
| Инструктор рядом | переключатель: на позиции строка «Расчётные данные: ↑ 2.4 ← 0.6 MIL» |
| Кнопка | «ЗАНЯТЬ ПОЗИЦИЮ» латунью, видна без прокрутки |

**Закрытое до курса** — видно с замком и подписью «откроется в упр. N», по `freePlayUnlocks`: неизвестная — после 05, САМ лёгкий — после 06, сложный — после 10, патроны А и В — после 08, порывистый — после 09, прицелы — по SCOPES.

**Выбор запоминается** (последние настройки — в прогрессе игрока); первый раз — 300 м, слабый ветер, курсовой прицел, патрон Б, АВТО, инструктор выключен.

## На позиции

- Та же позиция, что в курсе: блокнот, барабаны, разбор после выстрела, сцена из фото. Адрес `/position/free`.
- **Серия бесконечная**: одна цель, магазин 5 патронов, «Сменить магазин», когда кончился (Б33). Выстрелы не оцениваются: нет класса, листа итога, рекорда; «пересчитать и повторить» нет.
- **Строка расчётных данных** при «Инструктор рядом» — под ячейками поправок: верная поправка по игровым формулам (`formulaCorrectionMil` с настоящими показаниями).
- **Подсказок обучения нет** — они курсовые. Рация («дошли патрон») работает.
- **«Назад»** — на экран настроек `/free`, без подтверждения: курс не прерывается.
- **Выстрелы пишутся в прогресс** (`shots`) с пометкой «свободная» — их покажет журнал (A7.2).

## Неизвестная дистанция, ветер, патрон

| Настройка | Условия сцены |

| штиль | без ветра |
| слабый | 2–2,5 м/с, один по трассе |
| умеренный | 4–6 м/с, один |

## Как сделано

- **`PositionTask`** — общее у упражнения и свободной игры (`kind: 'exercise' | 'free'`). `ExerciseDef` его расширяет; `isExerciseTask` отделяет курсовое: итог, оценка, сценарии инструктора, забытый фактор, «Упр. N». `setupExercise` → `setupTask`: у свободной игры план `free`.
- **Задание строится из настроек** при входе на позицию: `freePlayTask(allowedFreePlay(сохранённое, открытое курсом))` — закрытое заменяется открытым ещё до позиции.
- **Строка инструктора** — `PositionSession.trueCorrection` (игровые формулы с настоящими показаниями; та же «правда», что в разборе причин, вынесена в `formulaTruth`).
- **Сохранённые настройки** читаются `knownFreePlay`: старое сохранение без них и мусор — умолчание.
- **Проверено в Chrome**: главная → настройки → 800 м, «Инструктор рядом» → позиция со строкой «↑ 9.4 ← 0.9 MIL» → «назад» с прежним выбором; закрытые патроны и режимы.

## Отступления от черновика

- **Неизвестная дистанция** — по правилу курса (никогда не кратна 50), а не «шагом 50»: иначе её угадывают круглым числом.
- **Гонг 0,7 м дальше 600 м** (правило курса), а не с 800 м.
- **Выстрелы свободной игры в прогресс пока не пишутся** — вместе с журналом (A7.2), где ясно, в каком виде они нужны.
- **E2 без стрельбы**: спуск с давлением и 5 выстрелов с затвором долги для e2e; бесконечную серию со сменой магазина даёт проверенный `FiringLine` с планом `free`. Тест проверяет позицию без оценки: заголовок, дистанцию, магазин, отсутствие листа итога.
