## Правила (решено мной)

- Профиль `builtin-custom` появляется у каждого игрока **один раз**: у нового — сразу, у старого — при следующей загрузке. Хранилище помнит это в `seededProfileIds`, поэтому удалённая винтовка не возвращается. Если активной винтовки не было, «своя-custom» становится активной, и в свободной игре «своя» — это она.
- Её можно править и удалять, как любую свою. **Бесплатное место она не занимает**: рядом можно завести ещё одну свою.
- **Оценки помечены.** `RifleProfile.estimates` хранит поля-оценки (скорость, разброс, кучность). В редакторе у них подпись «оценка — замени замером»; это не ошибка, сохранять можно. Вписал своё значение — пометка у этого поля снимается.

## Как сделано

- `sim/rifle-profile.ts`: `BUILT_IN_PROFILE_ID`, `builtInProfile()`, `withBuiltInProfile(stored, seededProfileIds)`, `EstimatedField`, `RifleProfile.estimates`. `canAddProfile` не считает встроенную. Хранимый профиль с неизвестной пометкой отбрасывается.
- `app/services/progress.store.ts`: `seededProfileIds` в состоянии; встроенная добавляется в начальное состояние и при загрузке.
- `app/rifle/rifle-form.model.ts`: подпись оценки в `fieldMessages`; `profileOf` снимает пометку с изменённого поля.
- Каталог: `content.builtInProfileName` («своя-custom»), `rifle.messages.estimate`.

## Тесты и мутации

| Тест | Мутация → красный |
| --- | --- |
| `rifle-profile.spec`: данные, проверка профиля, оценки, «один раз», не занимает место, хранится с пометками | занимает слот; удалённая возвращается; не становится активной; ноль 100 м; прицел MIL; пометки не хранятся |
| `rifle-form.model.spec`: подпись оценки; правка снимает пометку | правка не снимает; подпись не показывается |
| `progress.store.spec`: новый игрок — есть и активна; старое хранилище — появляется; удалил — не возвращается | хранилище и загрузка без встроенной |
| `profile-dope.spec`: карточка строится, ноль на 50 м, клики ½ MOA | — |
| e2e `rifle`, `free-play` (chromium и webkit): в списке сразу «своя-custom», подпись оценки, ДОПЕ, можно завести ещё одну, «своя» в свободной игре — она | — |

Старые e2e экрана «Винтовка» засевают `seededProfileIds` со встроенной («уже показана и удалена»), чтобы проверять прежние сценарии с пустым списком.
