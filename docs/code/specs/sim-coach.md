# sim · совет тренера (T3.4)

Статус: в работе 21.11 (логика — решено мной).
Задача бэклога: T3.4. Решения: В36 (тренер советует по слабому месту: ошибки + давность), В33 / В44 (инструктор → тренер), В57 (все дрилы открыты). Перед: T3.1 (каталог), T4.1–T4.2 (рейтинг). Дальше: T3.5 (экран «Дрилы» показывает совет сверху).

## Зачем

Игрок свободно берёт любой дрил, но новичку нужен ответ «что тренировать сейчас». Тренер выбирает навык по слабости и давности и называет причину.

## Правила

### Занятие навыка

Совет считается по «занятиям» — `{ навык, время, неудача, типы ошибок }`:

- выстрел журнала — попытки T4.1 / T4.2 (`attemptsFromJournalShot`), время — начало серии; неудача — исход 0; типов ошибок нет (у выстрела они не привязаны к навыку);
- карточка счётного дрила — навык дрила; неудача — ошибка или «время вышло»; типы ошибок карточки. На уровне «на время» — ещё занятие «скорость» с той же неудачей, без типов;
- раунд дрила на позиции — одно занятие навыка дрила без неудачи (его выстрелы уже в журнале) и «скорость» из попыток раунда на время.

Раунд «на время» дрила скорости засчитывает занятие, даже если рейтинг «скорости» не сдвинулся (на обучении «скорость» не оценивается) — иначе совет застрял бы на ней.

### Приоритет

`приоритет = (1 − рейтинг / 100) + min(дней с последнего занятия / 7; 1)`; навык без занятий — давность 1. Советуется навык с наибольшим приоритетом; при равенстве — по порядку навыков.

### Дрил совета

Навык → дрил: дальность — миллинг, ДОПЕ — ДОПЕ, ветер — ветер, условия — условия, угол — угол, упреждение — упреждение (счётные: быстрее и точнее чинят расчёт); исполнение — холодный выстрел, скорость — этап на время. Уровень — «на время», если он открыт (T3.3), иначе обучение.

### Причина

Первая подходящая:

1. **Ошибки:** за последние 7 дней ≥ 2 неудач навыка — «3 ошибки за неделю», и если у неудач есть типы — «, чаще СТОРОНА» (самый частый тип; при равенстве — по порядку типов проверки).
2. **Не тренировали:** занятий нет — «ещё не тренировали».
3. **Давно:** с последнего занятия ≥ 7 дней — «не тренировали 9 дней».
4. **Слабее:** иначе — «рейтинг 38 из 100».

### Тексты

«Инструктор» на экранах → «тренер» (В44): «с тренером» на брифинге, «Тренер рядом» в свободной игре. Звание «Снайпер-инструктор» уйдёт вместе со званиями (T4.2, REMOVAL-CANDIDATES).

Вид совета для T3.5: заголовок «Тренер: ветер», дрил с уровнем, причина, ссылка на дрил.
