# app · итог упражнения и карточка брифинга

Статус: реализовано 9.11, слито в `master`. Юнит-тестов 606. e2e 130 (по 65 на mobile-chromium и mobile-webkit) на собранном приложении: 128 зелёных, два длинных сценария на WebKit упёрлись в 60 с под нагрузкой полного прогона — помечены медленными, отдельно проходят за 20 и 11 с.
Задача бэклога: A6.3. Решения: В16, В17, В20, В4. Брифы [07](../../design/briefs/07-result.md) (итог) и [06](../../design/briefs/06-briefing.md) (только карточка; подсказки инструктора и переключатель «с инструктором» — A6.4). Логика: [COURSE](../../logic/COURSE.md), [FORMULAS «Оценка»](../../logic/FORMULAS.md). Уже есть:
- `sim/course.exerciseResult` — очки, доля, класс, допуск;
- `courseProgress` — открытые упражнения, следующий узел, звание;
- лист упражнения `/course/:id` — факты задания и кнопка «НА ПОЗИЦИЮ»;
- временная карточка итога на позиции (`endCard`) — «Класс 2 · 85 очк. · 85 %».

## Зачем

После упражнения игрок видит только «Класс 2 · 85 очк.». Не видно, какая цель класса не далась и почему, что открылось, какое звание. Перед упражнением лист — сухой список фактов: нет норматива классов, нет «что нового».

## Итог упражнения (бриф 07)

Бумажный лист на весь экран поверх позиции. Открывается после «ДАЛЬШЕ» в разборе последнего выстрела, вместо временной карточки.

| # | Блок | Как |
| --- | --- | --- |
| 1 | Штамп | «1 КЛАСС» (золото) / «2 КЛАСС» (серебро) / «3 КЛАСС» (бронза) / «НЕ ЗАЧТЕНО» (красный карандаш). Крупно, под углом −5°, появляется с ударом и вибрацией |
| 1а | Повтор с улучшением | прежний лучший класс зачёркнут графитом рядом со штампом |
| 1б | Новое звание | плашка «Звание: Стрелок» под штампом, если звание выросло |
| 2 | Три цели классов | по строке на класс, ✓ или ✕ и факт: «3 класс · ≥ 70 % очков — 85 % ✓», «2 класс · ≥ 85 % и скорость перенесена без ошибки — 3 из 3 ✓», «1 класс · все первым и вклад ветра на всех — 2 из 3 ✕». Текст — чернилами, цвет класса — маркером слева (бриф 06, «нельзя») |

| 5 | Главная ошибка | красным карандашом: «3 из 5 — недооценка ветра». При 1 классе — «Ошибок нет» |
| 6 | Новое | при первом допуске: термины упражнения по одному («новый термин»), строка «Открыто: 05 · Дистанции: ДОПЕ и дальномер» |
| 7 | Кнопки | «ДАЛЬШЕ» (латунь) — на тропу курса · «ПОВТОРИТЬ» — на брифинг этого упражнения · «В ЖУРНАЛ». Не зачтено: «ДАЛЬШЕ» скрыта, «ПОВТОРИТЬ» — латунь |

### Правила (решено мной)

- **Цели классов — из курса, а не из текста.** `sim/course` для каждого упражнения отдаёт навыковые цели вместе с фактом: сколько из скольких (или величину в MIL для 02). Тексты целей — в описании упражнения (`ExerciseDef.goals`), из таблицы COURSE. Брифинг и итог берут их оттуда же.
- **Строка класса выполнена**, если выполнены доля и навыковая цель этого класса. Классы накопительные, поэтому при ✕ во 2 классе строка 1 класса тоже ✕.
- **Главная ошибка** — самый частый главный лепесток разбора (A6.2) среди выстрелов серии. Оценка ветра делится на «недооценку» и «переоценку». Ничья — по порядку лепестков. Если ни у одного выстрела главного лепестка нет, а класс не 1 — первая невыполненная цель: «Не выполнено: вклад ветра на всех».

| Главный лепесток | Фраза |
| --- | --- |
| расчёт | ошибка расчёта |
| ветер, недооценка / переоценка | недооценка ветра / переоценка ветра |
| удержание | удержание сетки |
| спуск | срыв спуска |
| ноль прицела | ноль прицела |

- **Рекорд** — лучшая сумма очков упражнения. Хранится рядом с лучшим классом (`CourseResults.bestTotals`).
- **Звание и «Открыто»** — сравнение `courseProgress` до и после записи результата.
- **«ДАЛЬШЕ» ведёт на тропу курса**, где виден открытый узел. «ПОВТОРИТЬ» — на брифинг (В16: брифинг перед каждым запуском).

## Граничные случаи

- **00** — итога нет (упражнение без оценки, и на позицию оно пока не ведёт).
- **Не зачтено** — следующий узел не открывается, «новое» не показывается, лучший класс не меняется; рекорд очков пишется.
- **Повтор хуже лучшего** — штамп нового класса, зачёркнутого нет, лучший класс остаётся.
- **Повтор после «пересчитать»** — итог такой же, множитель ×1.0 уже в очках (A6.1).
- **02** — бумажная мишень: в строке очков «попаданий 4 из 5», цели 2 и 1 класса — в MIL («группа 0.8 MIL ≤ 1.0»).

## Как сделано

- **Цели классов с фактом.** `SkillGoals` стал `{ skill, top }` из `GoalCheck { isMet, passed?, total?, valueMil?, limitMil? }`. Счёт ведёт один помощник `tally` (прежний `everyRecord` с тем же правилом: пустой список — не выполнено). 02 отдаёт размер группы и промах контрольного в MIL, 11 — число поражённых целей, 12 — только «да / нет». Классы во всех прежних тестах `sim/course` те же.
- **Тексты целей и «Новое»** — таблицы `GOAL_TEXTS` и `NOVELTIES` по номеру упражнения в `sim/course`, `exerciseDef` берёт их сам.
- **Разбор очков** — `ExerciseResult.score { targetSum, calcSum, multiplier, referencePenalty }`. Строка «× 1.5 = 83» берёт итог до штрафа справочника, чтобы не считать округление второй раз.
- **Главный лепесток выстрела** пишется в запись (`ExerciseShotRecord.mainCause`, `mainCauseOf` в `sim/miss-breakdown`).
- **Рекорд** — `CourseResults.bestTotals`, необязательное поле: старые сохранения читаются без него.
- **Лист итога** открывается в `closeReview`. Курс до записи результата снимается заранее, чтобы сравнить звание, открытые узлы и лучший класс. Штамп появляется с ударом (`FeedbackService`, событие `stamp`).
- **Брифинг** — `briefingCard` поверх прежнего `exerciseSheet`; факты задания и их `data-test` остались. Заголовок листа теперь только название, номер — в шапке «ЗАДАНИЕ 04 · УЧЕБНОЕ».

## Отступления от черновика

- **`exerciseSheet` не переехал** в `briefing.model`: карточка строится поверх него, переносить было незачем.
- **Мишень серии** — вызовы мелкими ✛ рядом с точками группы.
- **Кнопки подтверждения выхода** с позиции переименованы из `end-*` в `confirm-*`: классы `end-*` уходили вместе с карточкой итога.

## Мутации

40 мутаций: 34 юнит, 6 e2e. Сначала выжили четыре:
- **«множитель в разборе очков без повтора»** — добавлена проверка `score.multiplier` в тесте повтора;
- **«главный лепесток не пишется в запись»** — добавлена проверка в тесте сессии;
- **«“Открыто” без допуска»** — эквивалентная: без допуска ничего не открывается. Лишнее условие убрано;
- **«термины скрыты»** — e2e считал элементы, но не видимость. Добавлена проверка видимости.
