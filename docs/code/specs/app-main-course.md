# app · главный экран и курс-тропа

Статус: реализовано 7.11, слито в `master`. Юнит-тестов 428, e2e 52 (по 26 на mobile-chromium и mobile-webkit) — все зелёные.
Задача бэклога: A2. Решения: В1 (вкладок нет), В28 (карточка «ПРОДОЛЖИТЬ», название курса), В20 (звания), В3 (курс), В15 («назад» ведёт туда, откуда пришли). Бриф [08](../../design/briefs/08-main-course.md). Логика — `sim/course` (S8).

## Зачем

Вход в игру: командное меню вместо нижних вкладок и путь по курсу 00–12 со штампами классов и званием. Первый экран на новой логике и токенах (A1).

## Что входит

| Экран | Содержание (бриф 08) |
| --- | --- |
| Главный `/` | шапка: звание и «допуски N / 12», шестерёнка; «ОГНЕВОЙ РУБЕЖ»; плитки 01 «Снайперская подготовка» · 02 «Свободная игра» · 03 «Учебник курсанта» · 04 «Журнал стрелка»; внизу карточка «НАЧАТЬ · 00» / «ПРОДОЛЖИТЬ · 05 …» / «СВОБОДНАЯ ИГРА» |
| Тропа `/course` | 13 узлов сверху вниз: номер, название, штамп (1 кл. — золото, 2 — серебро, 3 — бронза), текущий пульсирует, закрытые — пунктир и замок; 00 — «пройдено» без штампа; 12 — «аттестация» со знаком «Снайпер»; шапка «СНАЙПЕРСКАЯ ПОДГОТОВКА · пройдено N / 12» и звание |
| Узел → брифинг | брифинг — A6. До него: лист упражнения только для чтения из `setupExercise` (что учит, цели и дистанции, условия, режим блокнота, термины); кнопка «НА ПОЗИЦИЮ» неактивна с подписью «позиция — следующий этап» |

Пока не готовы экраны 03 «Учебник» (A7) и вводное 00 (A7): плитка и узел видны, тап — «откроется позже» (не ошибка, не пустой экран).

## Правила (решено мной)

- **Маршруты плоские**, без `tabs/`: `/`, `/course`, `/course/:exerciseId`, `/settings`, `/journal`, `/journal/:shotId`. Системная «назад» — по истории (В15); на главном — выход из приложения (Capacitor), не в пустоту.
- **Прогресс курса хранится** в `progress.store` новым полем `course: { isIntroCompleted, bestClasses }`; повтор не снижает класс (`mergeBestClass`, S8). «Сбросить прогресс» чистит и его. «Открыть всё» открывает узлы, звание не меняет (S8).
- **Модель экранов — чистые функции** рядом с экранами (`home.model.ts`, `course-trail.model.ts`): карточка «ПРОДОЛЖИТЬ», узлы тропы, подписи званий. Их и проверяют юнит-тесты; компоненты только рисуют.
- **Звания по-русски:** Курсант · Стрелок · Старший стрелок · Снайпер · Снайпер-инструктор (В20).
- **Живой фон** (качание сетки, дымка, В26) — A9 вместе со сценой. В A2 фон статичный, по токенам.
- **Касание ≥ 44, текст ≥ 13** — на новых экранах только токены, никаких `--hub-*`.

## Что удаляется в A2 (В31, ответ автора — Б)

Правило автора: старое удаляем, когда до него доходим, — без смешения легаси и новой логики.

| Что | Что вместо |
| --- | --- |
| `app/tabs` (нижние вкладки) | главный экран, плоские маршруты |
| `app/hub` (хаб, список 9 задач) | главный экран и тропа |
| `app/quiz`, викторины | шаги упражнений курса (COURSE) |
| `sim/tasks.ts` (+ тесты) | `sim/course.ts` |
| `core/score.ts` (+ тесты), звёзды, `TaskResult`, `results`, `passedTaskIds` | `exercise-scoring` (C6), прогресс курса |
| уровни задач в старом потоке (давление закрыто до Lv3, `shotsLeft`, итог задачи на прицеле) | свободная игра: всё открыто, патроны без счёта (Б31) |

**Свободная игра до A7** — тот же старый поток погода → расчёт → прицел, но без задач: `GameSession` настраивается сам (патрон Б, курсовой прицел Ёлка, гонг 500 м, ветер по зонам, зерно дня). Это последний старый поток; его заменяют A3 (позиция), A5 (блокнот), A7 (свободная игра по брифу 09).

**Упражнения курса до A3** — только лист упражнения для чтения.

## Как сделано

- Модели — `home/home.model.ts` (карточка, звание, запись прогресса курса) и `course/course-trail.model.ts` (узлы тропы, лист упражнения); компоненты только рисуют. Лист упражнения собирается из `ExerciseDef` (диапазоны, а не дистанции конкретного зерна).
- `progress.store`: поле `course` вместо `results`; `recordExerciseResult`, `completeIntro`; запись через `mergeBestClass`.
- `GameSession` без задач: свободная стрельба настраивается сама (патрон Б, курсовой прицел Ёлка, гонг 500 м, ветер по зонам, зерно дня); давление открыто сразу; выстрелы без счёта.
- Маршруты плоские; ссылки старых экранов (`calc`, `wind`, `scope`, `debrief`, `log`, `settings`) переведены на новые адреса; кнопка прицела «Хаб» → «Меню».
- e2e: хаб и викторины удалены вместе с кодом; поток расчёта и прицела идёт через плитку «Свободная игра»; новый `main-course.spec.ts`. Скрипт снимков снимает главный, тропу и лист упражнения.
- `tsconfig.spec.json` получил типы Node (тест токенов A1 читает файлы) — найдено по ходу, в A1 проверка типов тестов не запускалась.
- Мелочи на дизайн (в A6 с брифингом): «100 м» на листе переносится по пробелу перед «м»; замок на закрытых узлах — эмодзи, не из палитры.
