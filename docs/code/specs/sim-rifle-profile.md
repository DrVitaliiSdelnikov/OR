# sim/rifle-profile · профиль винтовки

Статус: реализовано 15.11, ветка `feat/rifle-profile`. Новых юнит-тестов 31 (26 `sim/rifle-profile`, 5 `progress.store`), мутаций 26 — все красят. Связанные юнит-спеки: 591 зелёный (ядро, каталог прицелов, блокнот, журнал, разбор, учебник, свободная игра, каталог текстов); числа курса и эталоны T1.3 не сдвинулись.
Задача бэклога: T1.5. Решения: В47 (кучность, холодный выстрел, BC), В34 (свой профиль, но не полевой калькулятор), В41 (бесплатно — один свой профиль, Pro — любое число; пока всё открыто), В42 (свои сетки по общим типам, без марок). Перед: T1.2 (снаряжение `Loadout`), T1.3 (ядро и эталоны lob). Дальше: T1.6 (ДОПЕ профиля), T1.7 (экран «Винтовка»), T3 (дрилы под профиль).

## Зачем

Игрок хочет тренироваться на своей винтовке: ДОПЕ, дрилы и задания должны считаться под его патрон и прицел (В34). Сейчас снаряжение — только учебное (`COURSE_RIFLE`, патроны А / Б / В). Эта задача даёт модель профиля, проверку ввода, пресеты и хранение. Экрана ещё нет (T1.7), ДОПЕ профиля — T1.6.

## Правила (решено мной)

### Модель

`sim/rifle-profile.ts`:

```ts
interface RifleProfile {
  id: string;            // 'profile-<время>-<счётчик>', пресет — 'preset-<код>'
  name: string;          // 1–40 символов
  rifle: { sightHeightCm; zeroM; twistInchesPerTurn; twistDirection; groupMoa; coldBoreShiftMil?: { upMil; rightMil } };
  cartridge: { muzzleVelocityMps; muzzleVelocitySdMps; dragModel: 'G1' | 'G7'; ballisticCoefficient; bcAtmosphere: 'asm' | 'icao'; massG; bulletDiameterIn; bulletLengthMm };
  scope: { units: 'MIL' | 'MOA'; clickValue; isFirstFocalPlane; magnificationMin; magnificationMax; reticle: ReticleKind };
}
```

- **Храним в метрике и в единицах, в которых их пишут производители**: скорость — м/с, высота прицела — см, длина пули — мм, масса — г, калибр и шаг нарезов — дюймы, цена клика — в единицах прицела (0,1 MIL или ¼ MOA). Перевод при вводе — форматтеры T1.1 на экране T1.7.
- **Кучность винтовки** `groupMoa` — размах группы из 5 выстрелов, как её меряют стрелки (по умолчанию 1 MOA). Ядру нужна сигма по оси: средний размах 5 выстрелов ≈ 3,08 σ, поэтому `groupSigmaMrad = groupMoa × 0,29089 / 3,08`. 1 MOA → 0,094 mrad (учебная винтовка — 0,1, то есть ≈ 1,06 MOA). 
- **Холодный выстрел — необязательное поле** (В47): смещение первого выстрела вверх и вбок. Не задано — смещения нет. Храним в MIL, как ядро (`coldBoreShiftMil`); на экране T1.7 — в единицах прицела.
- **BC по атмосфере.** Производители дают BC в Army Standard Metro, ядро считает в ICAO (T1.3). Разница на 1000 м — 0,3 MIL. При переводе в снаряжение: `BC_ICAO = BC_ASM × ρ_ASM / ρ_ICAO` (0,0751 / 0,0765 lb/ft³ ≈ 0,982). Поле «BC по: производитель (ASM) / ICAO» — в расширенных настройках профиля, по умолчанию ASM (В47).
- **Профиль → снаряжение и прицел:** `loadoutOf(profile): Loadout` и `scopeOf(profile): ScopeModel`. Ядро, карточка ДОПЕ и прицел работают с ними как с учебными. Для прицела второй плоскости метки верны на максимальной кратности — как у старого 3–12× из каталога.
- **`Cartridge.id` становится `string`.** Для курса остаются `CartridgeId` 'A' | 'B' | 'C' (этапы 08, записи «в ДОПЕ» — по букве); у патрона профиля `id` — `id` профиля. Ноль ядра кэшируется по числам, не по `id` (T1.2), поэтому смешения нет.
- **`ScopeModel.id` становится `string`**: у прицела профиля `id` — `id` профиля. Каталог S11 и `scopeById` не меняются.

### Проверка ввода

`validateProfile(profile): ProfileIssue[]`, где проблема — `{ field, kind: 'error' | 'warning', limits? }`. Ошибка не даёт сохранить, предупреждение — даёт.

| Поле | Ошибка вне |
| --- | --- |
| имя | 1–40 символов после обрезки пробелов |
| скорость | 300–1300 м/с |
| разброс скорости | 0–30 м/с |
| BC | G7: 0,1–0,5; G1: 0,2–1,0 |
| масса пули | 1–60 г |
| калибр | 0,17–0,51″ |
| длина пули | 10–60 мм и не короче калибра |
| ноль | 25–300 м |
| высота прицела | 2–10 см |
| шаг нарезов | 6–16″ |
| кучность | 0,2–5 MOA |
| холодный выстрел (если задан) | вверх и вбок каждое не больше 1 MIL по модулю |
| цена клика | MIL: 0,05 / 0,1 / 0,2; MOA: ⅛ / ¼ / ½ |
| кратность | 1–40×, мин ≤ макс |

- **Устойчивость пули** — предупреждение, не ошибка: Sg по Миллеру `30·m / (t²·d³·l·(1 + l²)) × ∛(V / 2800)` (m — граны, d — калибр в дюймах, t и l — шаг и длина в калибрах, V — фут/с) меньше 1,4 → «пуля может быть неустойчива». На эталонах T1.3: .223 77 гр (1:8) — 1,74; .308 175 гр (1:10) — 2,40; 6,5 мм 140 гр (1:8) — 1,71; .338 300 гр (1:10) — 2,00; .223 77 гр в 1:12 — 0,77 (предупреждение). Поправку Sg на атмосферу не берём: она меньше 5 % на равнине.
- **Ядро.** Профиль, прошедший проверку, должен строить траекторию до 1000 м без ошибки ядра — тест на границах диапазонов.

- Общее у пресетов: ноль 100 м, высота прицела 5 см, кучность 0,75 MOA, разброс скорости 5 м/с, прицел MIL 0,1, первая плоскость, 5–25×, ёлка.

### Хранение

- `ProgressState.profiles: RifleProfile[]` и `activeProfileId: string | null` (`null` — учебная винтовка курса).
- `knownProfiles(stored)` при загрузке: отбрасывает профили, которые не проходят проверку (ошибки), и `activeProfileId` без профиля. Так испорченное хранилище не ломает ядро.
- Методы `ProgressStore`: `saveProfile` (новый или правка по `id`), `removeProfile` (активный → `null`), `setActiveProfile`.
- **Лимит бесплатной версии** (В41): `canAddProfile(profiles, isProUnlocked)` — бесплатно один свой профиль. Флаг `isProUnlocked` пока всегда `true` (на время проверки спроса открыто всё), включается в T6.2. Пресеты в лимит не входят — их нет в списке своих.

## Решения автора (В47, 15.11)

- **Кучность — основное поле**, по умолчанию 1 MOA. **Холодный выстрел — необязательные поля** смещения вверх и вбок; пусто — без смещения.
- **BC: поле «по ASM / ICAO»** в расширенных настройках, по умолчанию ASM; перевод в ICAO делает игра.

## Не входит

- ДОПЕ профиля, печать и экспорт — T1.6.

## Как сделано

- `sim/rifle-profile.ts`: `RifleProfile`, `validateProfile` (ошибки с пределами, предупреждение `stability`), `millerStability`, `loadoutOf`, `scopeOf`, `PROFILE_PRESETS` и `profileFromPreset` (глубокая копия), `canAddProfile`, `knownProfiles`. Имена пресетов — в каталоге (`text.content.profilePresets`).
- Типы: `Cartridge.id`, `ScopeModel.id` и `DopeCard.cartridgeId` — `string`. Каталоги курса остаются узкими: `CourseCartridge` (`id: CartridgeId`) и `CatalogScope` (`id: ScopeId`). Буква патрона на экранах — `cartridgeLetter(id)`: у курса буква, у профиля пока `id` (имя профиля в карточке — T1.6). Записи «в ДОПЕ» (`DopeNotes`) — по строковому ключу патрона.
- `ProgressStore`: `profiles`, `activeProfileId`, `activeProfile`; `saveProfile` возвращает `false` для профиля с ошибками и ничего не пишет; `setActiveProfile` не принимает неизвестный `id`; `removeProfile` сбрасывает активный. Старое хранилище без профилей грузится как «профилей нет, учебная винтовка».
- Предупреждение об устойчивости считается, только когда нет ошибок: иначе Sg от неверных чисел бессмыслен.

## Отступления от черновика

- **Ход барабанов у прицела профиля** в черновике не был задан. Взял 30 MIL по вертикали и 10 по горизонтали — как у распространённых дальних прицелов; тест проверяет, что хватает на 1000 м самого медленного пресета. Поле хода — кандидат в T1.7, если игроки попросят.
- **Профили на границах диапазонов** (300 м/с с BC G7 0,1; 1300 м/с с G1 1,0; ноль 25 и 300 м; шаг 6″ левый и 16″; пуля 1 и 60 г) строят ДОПЕ до 1000 м без ошибки ядра — пределы проверки менять не пришлось.
- e2e в T1.5 нет (экрана нет). Связанные e2e на сборке прогнаны из-за смены типа ключа патрона: журнал, шторка блокнота, разбор, свободная игра.
- В `textbook.model.spec` есть старая ошибка типов (`ExerciseClass` импортируется из `sim/course`) — была в `master` до этой задачи, на тесты не влияет; не трогал.
