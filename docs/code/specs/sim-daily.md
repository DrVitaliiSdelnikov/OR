# sim + app · задание дня (T5.1)

Статус: реализовано 21.11, ветка `feat/daily`. Продуктовые решения — автор 21.11: позиция дня — 3 гонга, САМ лёгкий, по 1 выстрелу на цель; вход — плитка «03 Задание дня» и экран `/daily`. Логика — решено мной.
Задача бэклога: T5.1. Решения: В35 (короткая ежедневная причина вернуться). Перед: T3.2, T3.3.

## Зачем

Одно задание на всех в день: коротко, сравнимо с друзьями, повод вернуться завтра (серия дней).

## Правила

### Задание

1. **Дата** — UTC, ключ `ГГГГ-ММ-ДД`. **Сид** — хеш ключа (FNV-1a), один на всех.
2. **Чередование:** чётный номер дня от 1970-01-01 — карточки, нечётный — позиция.
3. **Карточки:** 10 карточек счётного дрила; дрил — `COUNT_DRILL_IDS[сид mod 6]`; уровень «обучение» (без таймера). Снаряжение учебное (своя винтовка не участвует), единицы игрока.
4. **Позиция:** 3 гонга 300–700 м (известная дистанция), ветер «умеренный», САМ лёгкий, по 1 выстрелу на цель, учебная винтовка, прицел «Ёлка»; сценарий — по сиду дня.
5. Два устройства с одной датой и одними единицами получают одно и то же задание.

### Зачёт

- **В зачёт идёт первая попытка** дня: закончившийся раунд (все 10 карточек или 3 выстрела). Повторы можно, но запись дня не меняют.
- **Запись:** дата, вид, дрил, попаданий / верных, из скольких, ошибка по ветру (позиция: средняя по выстрелам сумма звеньев ветра, MIL; карточки — нет).
- **Серия дней:** подряд идущие дни с записью, заканчивающиеся сегодня; если сегодня ещё не сделано — заканчивающиеся вчера.
- Попытка дня — ещё и обычный раунд дрила (рейтинг, журнал).

### Экраны

- **Главный:** плитка «03 Задание дня» (остальные сдвигаются), под названием «сделано · серия N» или «новое».
- **`/daily`:** дата, что сегодня («Ветер · 10 карточек» / «3 гонга · САМ лёгкий · 1 выстрел»), «НАЧАТЬ» (после зачёта — «ЕЩЁ РАЗ · БЕЗ ЗАЧЁТА»); итог зачётной попытки, серия, «ПОДЕЛИТЬСЯ».
- **Поделиться:** «Огневой рубеж · 14.11 · 2 из 3 · ветер 0,2 MIL» / «Огневой рубеж · 15.11 · Ветер · 8 из 10». Системное «Поделиться» (Web Share), иначе копирование в буфер и надпись «скопировано».
- Итог раунда дня ведёт «к заданию дня» вместо «к дрилам».

## Готово, когда

- Юнит: ключ даты по UTC; сид одинаковый для даты и разный для соседних; чередование; дрил дня; позиция дня; запись из карточек и выстрелов (ошибка по ветру); первая попытка; серия; текст.
- e2e: одинаковое задание при двух загрузках в одну дату (часы зафиксированы); карточный день: 10 карточек → запись, повтор не меняет; плитка «сделано»; «Поделиться» копирует текст.
- Мутации на каждый новый тест.

## Как сделано

- `sim/daily.ts`: `dailyDateKey`, `dailySeed` (FNV-1a), `dailyTask`, `dailyPositionTask(system)`, `dailyFromCards`, `dailyFromShots` (ветер — звенья с навыком «ветер» по `SKILL_OF_CAUSE`, теперь экспортирован), `withDailyRecord` (первая попытка), `dailyStreak`, `dailyShareText`, `shortDate`. Тексты — `i18n/ru/daily.ts`.
- `app/daily/daily.model.ts`: `dailyView`, `dailyTileLine`, `knownDailyRecords` (проверка записей из хранилища). Экран `daily.page.ts`, маршрут `/daily`; «Поделиться» — `navigator.share`, иначе `clipboard.writeText` и «Скопировано».
- Хранилище: `daily: DailyRecord[]`, `addDailyRecord`; сброс прогресса очищает.
- Карточки дня: `/drill/:id?daily=on` — режим дня, только если дрил совпадает с дрилом сегодняшнего дня; сид дня, учебное снаряжение, уровень «обучение»; запись дня после 10 карточек; «к заданию дня».
- Позиция дня: `/position/daily` — `dailyPositionTask`, сид дня, по концу серии — запись дня, итог раунда (как у дрила), «к заданию дня»; серия пишется в журнал как свободная с названием «Задание дня».
- `positionCards(records)` вынесен из `positionDrillRecord` (`sim/drill-levels.ts`).
- Главный: плитка «03 Задание дня» с пометкой «новое» / «сделано · серия N»; Винтовка, Учебник, Прогресс — 04–06.

## Отступления от спеки

- Ошибка по ветру — модуль суммы звеньев ветра выстрела (со знаком внутри выстрела), средняя по выстрелам: так ветер, ушедший в одну сторону, не гасится и не удваивается звеньями.
- e2e позицию дня до итога не проходит (стрельба на позиции долгая); запись из выстрелов — юнит. Учебное снаряжение в карточках дня при своей винтовке и сид дня на позиции e2e не проверены.

## Мутации

| Тест | Мутация → красный |
| --- | --- |
| `daily.spec` | дата по местному времени; сид не зависит от даты; чередование наоборот; дрил всегда первый; позиция: 5 целей, АВТО, 2 выстрела, слабый ветер; карточки: «близко» — верно; ветер: модуль каждого звена; ветер: все звенья; повтор заменяет зачёт; серия без вчера; серия не рвётся; ветер в тексте до сотых; текст карточек без дрила |
| `daily.model.spec` | всегда «Начать»; дрил без режима дня; серия и при нуле; ветер и у карточек; плитка «сделано» по любой дате; хранилище: дата любая, попадания строкой, вид любой |
| e2e `daily` | сид дня не используется; запись дня не сохраняется; итог ведёт к дрилам; «Поделиться» не копирует; плитка всегда «новое»; записи дня не читаются из хранилища; позиции дня нет |
