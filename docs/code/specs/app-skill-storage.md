# app · хранение рейтинга и пересчёт журнала (T4.2)

Статус: реализовано 20.11, ветка `feat/skill-storage` (логика — решено мной).
Задача бэклога: T4.2. Решения: В39. Перед: T4.1 (`sim/skill-rating`), T2.3 (величины причин в журнале). Дальше: T3.4 (совет тренера), T4.3 (экран «Прогресс»).

## Зачем

T4.1 умеет считать попытки, но рейтинг нигде не живёт. Нужно: рейтинг в хранилище, рост от каждой новой серии и раунда дрила, один пересчёт по уже накопленному журналу у тех, кто играл до T4.2, и рост навыков на итоге упражнения вместо таблички звания.

## Правила

### Хранение

- В хранилище `skills`: рейтинги навыков и учёт `ratedShots` — сколько выстрелов каждой серии журнала уже в рейтинге.
- Серия журнала пишется повторно (при уходе, сворачивании, конце) и заменяется по `id`. Поэтому в рейтинг идут только выстрелы серии сверх уже учтённых. Учёт держится только для серий, что остались в журнале.
- Раунд дрила дописывается один раз — его попытки идут в рейтинг при записи.
- Сброс прогресса сбрасывает и рейтинг.

### Пересчёт

- Хранилище без `skills` (игра до T4.2, перенос из v1) или с битым `skills`: рейтинг один раз пересчитывается по журналу и раундам дрилов в порядке времени начала. Серия и раунд с одним временем (дрил на позиции) — сначала серия. После этого `skills` записан, пересчёт больше не повторяется.
- Выстрел с величинами причин — как в T4.1.
- Выстрел без величин (записан до T2.3) — по грубой причине:
  - попадание — исполнение 1, ветер 1, если дул, ДОПЕ 1 в ручных режимах;
  - промах с причиной — 0 навыку причины: расчёт → ДОПЕ, недокрут / перекрут по ветру → ветер, упреждение → упреждение, удержание, спуск, ноль → исполнение; остальные навыки выстрела не оцениваются;
  - промах без причины — попыток нет.

### Поправка к T4.1

Выстрел «время вышло» лежит и в журнале, и в раунде дрила на позиции. «Скорость» 0 за него даёт только раунд; сам выстрел попыток не даёт — иначе ошибка считалась бы дважды.

### Итог упражнения

- Табличка «Звание: …» убирается; вместо неё — строки роста навыков: «ветер 41 → 44», вверх или вниз. Рейтинг до — снимок на начале серии, после — после записи серии.
- Показываются навыки, у которых изменился округлённый рейтинг, в порядке навыков; изменений нет — строк нет.
- `rankFor` и звания курса → `@deprecated` (они ещё на главной, тропе и в журнале — уйдут с T3.5 и T4.3).

## Готово, когда

- Юнит: дописанная серия не учитывается дважды; учёт держится для серий журнала; раунд даёт попытки при записи; сброс; пересчёт хранилища без `skills` и с битым `skills`, порядок по времени; грубая причина; выстрел «время вышло» без попыток; строки роста на итоге.
- e2e: итог упражнения показывает рост навыков.
- Мутации на каждый новый тест.

## Как сделано

- `app/services/skill-ledger.model.ts`: `SkillLedger` (`ratings`, `ratedShots`), `emptyLedger`, `attemptsFromJournalShot` (с величинами — `attemptsFromShot`, без — `attemptsFromRoughShot`), `withRatedSeries`, `withRatedRound`, `replayedLedger`, `knownLedger` (проверка поля из хранилища).
- `sim/skill-rating.ts`: `attemptsFromRoughShot`, `SKILL_OF_MAIN_CAUSE`; выстрел «время вышло» попыток не даёт; `ShotForRating.isHit`.
- `ProgressStore`: поле `skills`, сигнал `skills()` (рейтинги); `addSeries` / `addDrillRound` двигают рейтинг, `resetProgress` сбрасывает; `load` пересчитывает журнал, если `skills` нет или он битый, и сразу записывает.
- Итог: `ResultSheetView.skillGrowth` и `skillGrowth(before, after)` в `result.model`; на листе — плашки `result-skill` («ветер 40 → 44 ▲», падение — пунктир и ▼). Позиция снимает рейтинг на начале серии (`skillsAtSeriesStart`).
- `rankFor` и `text.result.rankPlate` → `@deprecated`, звания — в REMOVAL-CANDIDATES.

## Отступления от спеки (решено мной)

- **Исполнение при попадании — 1 (поправка к T4.1).** e2e показал: три чистых попадания в 01 роняли «исполнение» 40 → 34 — удержание 0,2–0,3 MIL больше клика. Клик — мера барабана, а не руки: удержание и спуск оцениваются по кликам только на промахе.
- Проверка «время вышло» в грубой ветке не нужна: запись таймаута без причин и без `mainCause`, она и так идёт как «промах без причины» (мутация показала мёртвый код — убран).
- Рост на итоге — только у упражнений курса; на конце дрила и свободной серии — с экраном «Дрилы» (T3.5) / «Прогресс» (T4.3).

## Мутации

| Тест | Мутация → красный |
| --- | --- |
| `skill-ledger.model.spec` | серия — все выстрелы заново; учёт без чистки; раунд не рейтингуется; с величинами — как грубо; грубо: ветер и в штиль, ДОПЕ и в авто; расчёт → ветер; промах без причины → исполнение 0; с величинами: время вышло засчитано; пересчёт без сортировки; раунд раньше серии; читается рейтинг вне 0–100, дробные попытки, битый учёт серий, учёт-массив, учёт без навыка |
| `skill-rating.spec` | исполнение без учёта попадания; попадание — 1 для всех навыков; время вышло засчитано |
| `progress.store.spec` | серия не двигает рейтинг; сброс не трогает рейтинг; без рейтинга — начальный, не пересчёт; пересчёт не записывается; целый рейтинг пересчитывается |
| `result.model.spec` | рост без округления; вверх наоборот; все навыки; рост не передан |
| e2e `result.spec` | позиция не передаёт рейтинг «до» |
