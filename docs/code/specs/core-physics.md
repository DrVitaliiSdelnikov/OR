# core · физика: угол места, деривация, высота, Кориолис, сверка с эталоном

Статус: реализовано 15.11, ветка `feat/physics`. Новых юнит-тестов 21 (12 `physics`, 4 `effects`, 4 `scenario`, 1 `shot`) + сверка с эталоном 17 (`reference.spec`); мутаций 17 — все красят, одна — эквивалентная (см. «Мутации»). Связанные спеки: 513 зелёных, числа курса не сдвинулись.
Задача бэклога: T1.3. Решение: В37 (физика + экран «Модель» + сверка с JBM / 4DOF). Перед: T1.2. Дальше: T1.4 (что из этого игрок считает сам, угломер и шаги проверки), T1.6 (колонка деривации в ДОПЕ).

## Зачем

Сейчас движок стреляет по ровной линии, на уровне моря, без вращения пули и Земли. Для своей винтовки на 600–1000 м этого мало. Деривация и Кориолис дают по 5–10 см на 1000 м, угол и высота меняют возвышение на целые MIL. И пока нечем доказать, что наш движок не врёт: нужна сверка с независимым калькулятором.

## Что умеет библиотека (проверено опытом 15.11, `js-ballistics` 3.1.0, патрон Б, ноль 100 м, 1000 м)

| Эффект | Как включается | Результат |
| --- | --- | --- |
| деривация | `Weapon.twist` (знак = направление) + `DragModel.length` | 0,46 MIL вправо при правых нарезах 10″, −0,46 при левых; возвышение не меняется |
| угол места | `Shot.lookAngle` | библиотека меряет дистанцию **по горизонтали**: при 15° точка «1000 м» лежит на наклонной 1035 м |
| высота над морем | `Atmo({ altitude, pressure })` | 1500 м, давление на станции 845,6 гПа: возвышение 13,0 вместо 15,5 MIL |
| Кориолис | `Shot.coriolis({ latitudeDeg, azimuthDeg })` | 55° с. ш.: 0,11 MIL вправо при любом азимуте; на восток −0,08 MIL, на запад +0,08 MIL по вертикали |

Физику пишем не сами: подаём библиотеке входы и переводим её систему отсчёта в нашу.

## Правила (решено мной)

- **Геометрия выстрела** — новый тип `ShotGeometry`:
  - `lookAngleDeg` — угол места, + вверх;
  - `coriolis: { latitudeDeg, azimuthDeg } | null`;
  - `isSpinDriftOn`.
  
  По умолчанию `FLAT_GEOMETRY`: 0°, без Кориолиса, без деривации. Высота над морем идёт в `Atmosphere.altitudeM` (необязательное поле, по умолчанию 0): это условие воздуха, оно же задаёт давление на станции.
- **`trajectory(loadout, atmosphere, windZones, muzzleVelocity?, step?, geometry = FLAT_GEOMETRY)`.** Геометрия идёт последним параметром со значением по умолчанию. Около 40 существующих вызовов не меняются, а курс стреляет как сейчас.
- **Дистанция в точках траектории — по линии прицела** (её меряет дальномер, и её игрок вводит в блокнот). При угле движок просит у библиотеки горизонталь `D × cos угла` и подписывает точку наклонной дальностью. Поправки — угол относительно линии прицела.
- **Деривация** включается флагом сценария, а не наличием нарезов. Нарезы теперь есть у винтовки курса (T1.2). Если включить деривацию всегда, сдвинутся ДОПЕ курса и калибровка констант ветра: снос на 1 м/с сейчас читается из той же горизонтали. В курсе она выключена, пока её не научит упражнение.
- **Ноль — на ровной линии, на уровне моря, без деривации и Кориолиса.** Так пристреливают на стрельбище, и ключ кэша нуля из T1.2 не меняется.
- **Вклад эффектов** — `effectContributions(engine, loadout, atmosphere, windZones, geometry, distanceM)` → `{ angle, spinDrift, coriolis }`, у каждого `{ upMil, rightMil }`. Вклад одного эффекта = прогон со всеми включёнными эффектами минус прогон без этого эффекта. Кэш — по ключу из всех входов. Сумма вкладов отличается от разности «всё / ничего» на перекрёстный член; он заметен только при угле больше 30° и в тесте ограничен 0,03 MIL.
- **Сценарий:**
  - в `ScenarioOptions` появляются `altitudeRangeM`, `lookAngleRangeDeg`, `coriolis` и `isSpinDriftOn`;
  - без них сценарий прежний;
  - давление на станции разыгрывается вокруг стандартного давления на высоте сценария (1500 м → около 846 гПа), а не вокруг 1013.
  
  Курс эти поля не задаёт, и его числа не меняются.
- **Сверка с эталоном:**
  - в `src/core/reference/<патрон>.json` лежат входы (масса, BC и модель, скорость, калибр, длина, шаг, высота прицела, ноль, атмосфера, ветер), источник, дата и таблица по дистанциям: возвышение, снос, деривация;
  - тест прогоняет те же входы через наш движок;
  - допуск: ≤ 0,1 MIL по вертикали и ≤ 0,05 MIL по ветру до 1000 м, деривация на 1000 м в пределах ±20 % от эталона;
  - не сходится — причину пишем в спеку, допуск не расширяем.
- **Четыре эталона:** .308 175 гр, 6,5 Creedmoor 140 гр, .223 77 гр, .338 Lapua Magnum 300 гр. Для каждого — два набора: на уровне моря без ветра и 4 м/с с 3 ч на высоте 1500 м.

## Тесты (сначала, каждый с мутацией)

| Тест | Мутация, которая красит |
| --- | --- |
| ровная геометрия: снимок курса T1.2 не меняется (`loadout.spec`) | деривация всегда включена |
| деривация: правые нарезы → вправо, левые → влево, по модулю равны; растёт с дальностью; флаг выключен → 0 | знак нарезов не передан |
| угол: ±15° на 800 м — возвышение меньше ровного; дистанция точек — по линии прицела | дистанция по горизонтали |
| угол: 0° даёт ровно ровную траекторию | `cos` от градусов без перевода в радианы |
| высота: 1500 м с давлением на станции — возвышение меньше, чем на уровне моря | высота не передана в `Atmo` |
| Кориолис: северное полушарие → вправо, южное → влево; на восток возвышение меньше, чем на запад; `null` → 0 | широта с обратным знаком |
| ноль не зависит от геометрии: две геометрии — одна пристрелка | пристрелка с углом выстрела |
| вклады: каждый эффект выключен → его вклад 0; сумма вкладов ≈ «всё − ничего» до 0,03 MIL; повторный вызов не гоняет движок | вклад «всё − ничего» вместо «всё − без эффекта»; без кэша |
| сценарий: `altitudeRangeM: [1500, 1500]` → давление на станции 800–890 гПа; без поля — как сейчас (снимок сида) | давление вокруг 1013 |
| эталоны: 4 патрона × 2 набора в допуске | эталон без деривации (нарезы не переданы) |

## Эталон: lob (решено 15.11)

JBM онлайн закрыт: калькуляторы «retired». Эталон считает открытая библиотека **lob** (`@joelbenway/lob` 0.14.0, C++ → WASM, GPL-3.0). Её код не связан с py-ballisticcalc / `js-ballistics`. Проверено на патроне Б (ноль 100 м, 15 °C, 1013 гПа, 50 %), 1000 м:

| Что | Наш движок | lob | ballistics-engine 0.50.1 |
| --- | --- | --- | --- |
| возвышение, MIL | 15,431 | 15,438 | 15,444 |
| снос на 1 м/с, MIL | 0,904 | 0,904 | 0,904 |
| время полёта, с | 2,154 | 2,154 | 2,154 |
| деривация, нарезы 10″ правые, MIL | 0,464 | 0,464 | 0,505 |
| Кориолис 55° с. ш., гор. / на восток верт., MIL | 0,107 / −0,075 | 0,107 / −0,069 | — |
| высота 1500 м, 845,6 гПа: сдвиг возвышения, MIL | −2,521 | −2,495 | — |

**Как подключаем:**
- скрипт `scripts/reference/` со своим `package.json`, версия закреплена, в сборку приложения не попадает;
- результат — `src/core/reference/*.json` с библиотекой, версией и датой;
- тест сравнивает наш движок с JSON, в CI ничего не скачивается.

**Особенности lob, которые учитывает скрипт:**
- BC отнесён к **Army Standard Metro** по умолчанию. С ним возвышение на 1000 м больше на 0,30 MIL (2 %). `js-ballistics` считает BC по ICAO, поэтому скрипт ставит `bcAtmosphere('ICAO')`.
- **Состояние течёт между запусками в одном процессе:** шаг нарезов переживает и новый `Builder`, и `reset()`. Поэтому каждый набор считается в отдельном процессе.
- Скорость принимается только целым числом fps: 800 м/с → 2625 fps, разница 0,1 м/с.
- Дальность по наклону — `rangeAngleDeg`. При +15° возвышение 15,07 MIL, при −15° — 14,73; вверх больше, чем вниз.

**ballistics-engine** в эталон не берём:
- возвышение, ветер и время совпадают с нашими до 0,013 MIL — слишком близко, чтобы считать это независимой проверкой;
- в простом API нет угла места и длины пули;
- выпуски еженедельные, интерфейс непостоянен.

**Вывод для T1.5:** профиль должен знать, к какой атмосфере отнесён BC (ICAO или ASM). Производители публикуют по-разному, а ошибка — 0,3 MIL на 1000 м.

## Как сделано

- **Эталон** — `scripts/reference/` (свой `package.json`, lob 0.14.0 закреплён в `package-lock.json`), `npm run generate` пишет `src/core/reference/*.json`. Каждый набор — отдельный процесс (утечка состояния lob). Четыре выравнивания (BC по ICAO, ровный ноль, без аэродинамического прыжка, ветер «куда дует») описаны в `logic/FORMULAS.md`, «Модель ядра и сверка с эталоном», и в `source.notes` каждого JSON.
- **Порог высоты библиотеки.** `js-ballistics` по умолчанию обрывает траекторию на −1500 футов: при −30° на 1000 м пуля ниже. Порог опущен до −10 000 футов (`maximumDrop`).
- **Высота в движок не передаётся.** При заданном давлении на станции библиотека её не использует (проверено: 13,2648 MIL на 1000 м при 0 и 1500 м, ровно и под 15°). Высота остаётся в `Atmosphere.altitudeM`: от неё сценарий разыгрывает давление на станции, её покажут приборы в T1.4.
- **Сценарий** берёт высоту и угол из отдельного генератора (`seed ^ TERRAIN_SEED_SALT`): без новых полей сценарий совпадает со снимком сида до T1.3.
- **Выстрел** (`resolveShot`) и полёт на позиции идут с геометрией сценария; в курсе она ровная.

## Отступления от черновика

- Тест «вверх больше, чем вниз» был неверен физически: сила тяжести вдоль пути и плотность воздуха почти гасят друг друга (lob ELR: 13,63 вверх и 13,65 вниз на 1000 м). Заменён на «оба меньше ровного на 0,2–0,6 MIL, почти поровну».
- Добавлен третий набор эталона (подъём 15° + Кориолис): без него угол и Кориолис проверялись бы только знаками.
- Время полёта сверяется сверх спеки: ≤ 1 % на ровной линии (факт 0,05 %), ≤ 1,5 % под углом (факт 1,07 %). Причина — в FORMULAS.
- Вклады эффектов — сдвиг попадания (`impactUpMil`, `impactRightMil`), а не поправка: так их увидит игрок на экране «Модель».

## Мутации

| Мутация | Упавшие тесты |
| --- | --- |
| деривация всегда (винтовка и пуля) | эталон: деривация 4 патрона; вклады |
| знак нарезов не передан | правые → вправо, левые → влево |
| дистанция без `/ cos` | вклады; эталон с углом |
| горизонталь = наклонная (шаг без `cos`) | эталон с углом 4 патрона; вклады |
| `cos` от градусов | вклады; эталон с углом |
| широта с обратным знаком | эталон с Кориолисом 4 патрона; вклады |
| ноль под углом выстрела (новый ноль на каждую геометрию) | одна пристрелка (физика и снаряжение) |
| порог высоты библиотеки по умолчанию | сетка при −30°; ноль под углом |
| без длины пули | эталон: все наборы и деривация |
| границы зон без `cos` | граница зоны по линии прицела |
| вклад = «всё − ничего» | вклад = «без эффекта − всё»; сумма вкладов |
| без кэша вкладов | повторный вызов не гоняет движок |
| давление вокруг 1013 на высоте | высота 1500 м: давление 800–890 |
| местность из общего генератора | высота 1500 м: ветер и время как без высоты |
| деривация из условий не берётся | угол, Кориолис и деривация из условий |
| выстрел без геометрии (все 6 вызовов) | выстрел следует геометрии сценария |
| высота не передана в `Atmo` | **никакие — эквивалентная мутация**: при заданном давлении высота не влияет. Строка удалена из движка |
