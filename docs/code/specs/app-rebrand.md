# app · ребрендинг «Симулятор снайпинга»

Статус: реализовано 22.11, ветка `feat/rebrand`. Решение автора 22.11 (В61): название «Симулятор снайпинга» / «Sniping Simulator»; военная лексика — только в названиях приложения и курса, внутри остаётся спорт (В44).
Задача: новая, вне бэклога (запрос автора 22.11), перед T6.3 «Английский».

## Правила

- Название — одна константа каталога `APP_NAME` (`i18n/ru/app-name.ts`): заголовок главного экрана и текст «Поделиться» задания дня.
- Вкладка: `index.html` — «Sniping Simulator» (до запуска язык неизвестен); при запуске `Title` ставит название из каталога.
- Сторож лексики ловит корень «снайп» (снайпер, снайпинг) везде, кроме названий «Симулятор снайпинга» и «Снайперская подготовка».
- `catalog-guard` пропускает статичный `index.html` (заголовок до запуска Angular из каталога не взять).

## Как сделано

- `APP_NAME` импортируют `screens.ts` и `daily.ts`; `App` вызывает `Title.setTitle(text.screens.home.title)`.
- Документация и имя репозитория не переименовывались: «Огневой рубеж» остаётся рабочим названием проекта в docs.

## Мутации

| Тест | Мутация → красный |
