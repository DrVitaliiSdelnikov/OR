# core/units · метрика и имперская система

Статус: реализовано 15.11, ветка `feat/core-units`. Юнит-тестов 11 (7 `core/units`, 3 подписи, 1 настройки), мутаций 12 — все красят. Тест «хранилище» слит с `knownSettings`: `ProgressStore` пишет настройки целиком, а читает через `knownSettings`, поэтому проверка — круг JSON → `knownSettings`.
Задача бэклога: T1.1. Решения: В38 (единицы сейчас, английский — перед сторами), В34 (свой профиль винтовки). Дальше: T1.4 (имперские игровые формулы), T1.5 (профиль), T1.8 (единицы на экранах).

## Зачем

Профиль своей винтовки (T1.5) вводят в тех единицах, в которых написано на коробке патронов и в паспорте прицела: граны, fps, дюймы, ярды. Сейчас все числа игры — метрические и разбросаны по каталогу текстов. Нужен один модуль, который переводит туда-обратно и знает шаг округления каждой величины.

## Правила (решено мной)

- **Хранение — в базовых единицах игры**, всегда: м, м/с, г, мм, °C, гПа. Система единиц — только показ и ввод. Числа курса, сценариев и ядра не меняются.
- **Величины и единицы:**

| Величина | Базовая | metric (показ, шаг) | imperial (показ, шаг) |
| --- | --- | --- | --- |
| `distance` дальность | м | м, 1 | ярд, 1 |
| `targetSize` размер цели | м | м, 0,05 | дюйм, 1 |
| `muzzleVelocity` скорость пули | м/с | м/с, 1 | фут/с, 1 |
| `windSpeed` ветер, скорость цели | м/с | м/с, 0,1 | миля/ч, 0,1 |
| `bulletMass` масса пули | г | г, 0,1 | гран, 1 |
| `bulletLength` длина пули | мм | мм, 0,1 | дюйм, 0,001 |
| `sightHeight` высота прицела | мм | мм, 1 | дюйм, 0,01 |
| `temperature` | °C | °C, 1 | °F, 1 |
| `pressure` | гПа | гПа, 1 | дюйм рт. ст., 0,01 |

- **Эталоны перевода** (точные, по определению): 1 ярд = 0,9144 м; 1 фут = 0,3048 м; 1 дюйм = 25,4 мм; 1 миля/ч = 0,44704 м/с; 1 гран = 0,06479891 г; 1 дюйм рт. ст. = 33,8639 гПа; °F = °C × 9/5 + 32.
- **Показ** округляет до шага системы. **Ввод** переводит в базовые без округления — округляет только показ.
- **Подписи единиц — в каталоге** (`i18n/ru/units.ts`), не в `core`.
- **`Settings.unitSystem`**, по умолчанию `metric`; неизвестное значение из хранилища → `metric`.
- **Переключателя в настройках пока нет:** без T1.8 он ничего бы не менял на экранах. Он появится в T1.8 вместе с единицами на экранах.
- **Десятичный разделитель по локали отложен до английского (T6.3).** Сейчас каталог один, русский, `decimal` уже ставит запятую; заводить локали ради одного языка — лишняя инфраструктура.

## core/units.ts

| Экспорт | Что |
| --- | --- |
| `UnitSystem = 'metric' \| 'imperial'` | система |
| `Quantity` | 9 величин из таблицы |
| `toDisplay(quantity, baseValue, system): number` | базовое → число для показа, округлено до шага |
| `fromInput(quantity, value, system): number` | введённое → базовое, без округления |
| `displayStep(quantity, system): number` | шаг: для клавиатуры и числа знаков |
| `displayDigits(quantity, system): number` | знаков после запятой по шагу (0,05 → 2) |

`i18n/ru/units.ts` (`text.units`): `unitLabel(quantity, system)` и `quantityText(quantity, baseValue, system)` → «275 ярдов», «2,5 м/с», «−4 °F», «1,228 дюйма» (через `decimal` и `plural`). Целое число склоняется по `plural`, дробь — родительный падеж единственного («2,5 ярда»). Лишних нулей нет: «0,5 м», не «0,50 м».

## Тесты (сначала, каждый с мутацией)

| Тест | Мутация, которая красит |
| --- | --- |
| эталоны: 100 ярдов → 91,44 м; 1 гран → 0,06479891 г; 29,92 inHg → 1013,2 гПа; 10 миль/ч → 4,4704 м/с; 1″ → 25,4 мм | сломать любой коэффициент |
| °F со сдвигом: 15 °C → 59 °F, −40 → −40 | убрать сдвиг 32 |
| показ округляет до шага: 0,5 м цели → 20″; 2,54 м/с ветра → 5,7 миль/ч | убрать округление |
| обратимость: ввод → базовое → показ возвращает введённое для каждой величины в обеих системах | перевод только в одну сторону |
| metric — тождество: 300 м → 300 | множитель вместо 1 |
| шаг и знаки: `targetSize` metric → 0,05 и 2 | шаг 0,1 |
| подписи: «1 ярд», «2 ярда», «5 ярдов»; «°F»; «миль/ч» | без `plural` |
| `knownSettings`: `unitSystem: 'imperial'` сохраняется, мусор → `metric` | принять любую строку |
| хранилище: `unitSystem` переживает перезагрузку | не сохранять поле |

## Не входит

- Единицы на экранах — T1.8.
- Имперский миллинг (27,78 / 95,5) и мили в формулах блокнота — T1.4.
- Локали и английский — T6.3.

## Мутации

| Мутация | Упавшие тесты |
| --- | --- |
| гран 0,0648 вместо 0,06479891 | эталоны перевода |
| сдвиг °F 0 вместо 32 | °F со сдвигом; подписи «−4 °F» |
| показ без округления до шага | показ округляет до шага |
| `fromInput` без сдвига (перевод в одну сторону) | °F со сдвигом; обратимость |
| `fromInput` округляет | эталоны; ввод не округляет; обратимость; metric — тождество |
| metric с множителем 1,01 | metric — тождество |
| шаг цели metric 0,1 | шаг и число знаков |
| целое без `plural` | ярды склоняются по числу |
| дробь в форме «ярдов» | дробь с запятой («1,228 дюйма») |
| пустая подпись °F | подписи; у каждой величины есть подпись |
| `unitSystem` — любая строка | система единиц в настройках |
| `unitSystem` не читается при загрузке | система единиц в настройках |
