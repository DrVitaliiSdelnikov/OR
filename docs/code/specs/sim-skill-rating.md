# sim · рейтинг по навыкам (T4.1)

Статус: реализовано 20.11, ветка `feat/skill-rating` (логика — решено мной; названия уровней — предложение, их можно поменять).
Задача бэклога: T4.1. Решения: В39 (рейтинг по навыкам и общий уровень вместо званий курса). Перед: T2.3 (причины выстрела с величинами), T3.2–T3.3 (раунды дрилов). Дальше: T4.2 (хранение и пересчёт журнала), T3.4 (совет тренера), T4.3 (экран «Прогресс»).

## Зачем

Звания курса говорят, сколько упражнений пройдено, но не что стрелок умеет. Рейтинг навыка — число 0–100: растёт от точных попыток, особенно трудных, падает от ошибок. Из рейтингов кормятся совет тренера и экран прогресса.

## Правила

### Навыки

Дальность, ДОПЕ, ветер, условия, угол, упреждение, исполнение, скорость — те же, что у дрилов (`DrillSkill`).

### Попытка

`{ skill, outcome: 1 | 0,5 | 0, difficulty: 0–100 }`.

- **Карточка счётного дрила:** навык дрила; точно / близко / ошибка → 1 / 0,5 / 0; «время вышло» — 0. На уровне «на время» ещё одна попытка навыка «скорость» с тем же исходом.
- **Выстрел (журнал, есть величины причин T2.3):** звенья цепочки и исполнение раскладываются по навыкам:

  | Навык | Звенья |
  | --- | --- |
  | дальность | дальность |
  | ДОПЕ | ДОПЕ, накрутка |
  | условия | условия |
  | ветер | скорость ветра, час ветра, зоны, расчёт ветра |
  | угол | угол, Земля |
  | упреждение | расчёт упреждения, упреждение сеткой |
  | исполнение | удержание, спуск, ноль |

  Навык участвует в выстреле, если у выстрела есть хоть одно его звено (журнал пишет звенья от 0,01 MIL, нулевые — нет). Исполнение участвует всегда, ветер — когда дул ветер, ДОПЕ — в ручных режимах. Исход — по самому большому звену навыка в кликах: 0 кликов — 1, 1 клик — 0,5, больше — 0 («звено больше клика — ошибка навыка»). Выстрел «время вышло» — только «скорость» 0.
- **Серия дрила на позиции:** её выстрелы уже в журнале, поэтому из раунда берётся только «скорость» уровня «на время»: попадание — 1, промах — 0,5, время вышло — 0.
- Выстрелы без величин (старые записи) попыток не дают — их один раз пересчитает T4.2 по грубой причине.

### Сложность попытки

`15 + дистанция (0–40: 100 м → 0, 1000 м → 40) + ветер (0–25: 0 → 0, 10 м/с → 25) + на время 20`, не выше 100. Без дистанции или ветра — их часть 0.

### Обновление

В духе Эло: `E = 1 / (1 + 10^((сложность − рейтинг) / 25))`, `рейтинг += 4 × (исход − E)`, рейтинг в пределах 0–100. Шаг за попытку — не больше 4. Начальный рейтинг — 40. Рейтинг не тает со временем: давность учитывает только совет тренера (T3.4).

### Общий уровень

Среднее рейтингов навыков, у которых была хотя бы одна попытка; нет попыток — уровня нет. Названия по порогам (спортивные, без званий):

| Порог | Название |
| --- | --- |
| < 40 | Начинающий |
| 40–54 | Любитель |
| 55–69 | Стрелок |
| 70–84 | Сильный стрелок |
| ≥ 85 | Эксперт |

## Готово, когда

- Юнит: серия точных растит, ошибки снижают, шаг ≤ 4, рейтинг в 0–100; трудная точная попытка даёт больше лёгкой; разложение выстрела по навыкам (звено 1 клик — 0,5, больше — 0; исполнение всегда; «время вышло» — только скорость); карточки и раунды на время; сложность; общий уровень и пороги.
- Мутации на каждый новый тест.

## Как сделано

- `sim/skill-rating.ts`: `SkillAttempt`, `SkillRatings`, `initialRatings`, `expectedOutcome`, `applyAttempt(s)`, `attemptDifficulty`, `attemptsFromShot` (вход — `ShotForRating`: дистанция, ветер, режим, причины, цена клика, «время вышло»; подходит и `JournalShot`, и запись выстрела), `attemptsFromDrillRound`, `overallLevel`. Тексты уровней — `i18n/ru/skills.ts`.
- Раунд карточек пишет у карточки `distanceM` и `windSpeedMps` (`CountCard.distanceM` — настоящая дистанция задачи, у миллинга тоже) — для сложности попытки.
- Хранения и пересчёта нет — это T4.2; экрана нет — T4.3.

## Отступления от спеки (решено мной)

- Потолок сложности 100 не нужен: дистанция и ветер упираются в свои пределы, максимум ровно 15 + 40 + 25 + 20 = 100 (мутация «без потолка» показала мёртвый код — убран).
- Навыки «дальность», «условия», «угол», «упреждение» в выстреле участвуют только при записанном звене: журнал не отличает «звено 0» от «шага не было». Звенья пишутся от 0,01 MIL, поэтому почти точный шаг всё равно засчитывается как попытка с исходом 1.
