# Документация «Огневого рубежа»

Карта документов. Контекст и решения не теряются между сессиями: у каждого решения есть один дом, остальные документы ссылаются на него.

## Правила

1. **Одно решение — один файл.** Число, формула или правило записаны в одном месте, остальные ссылаются туда. Копия = будущее расхождение.
2. **Холсты — референс вида и UX.** Логику (физику, формулы, оценку, единицы, согласованность чисел) решает Claude. Автор отвечает на продуктовые и UX-вопросы.
3. **Поток решения:** вопрос → ответ в [QUESTIONS.md](QUESTIONS.md) → правило в `logic/` или `design/` → бриф экрана в `design/briefs/` → задача в [code/BACKLOG.md](code/BACKLOG.md).
4. **Отложенное** — в одной таблице «Отложено на будущее» в QUESTIONS.md, пополняется сразу.
5. **Порядок работы над кодом (7.11):** спека модуля → юнит-тесты важной логики → код и шаблон → пользовательские тесты; всё проверяется в симуляции телефона (Playwright) и в мобильном браузере на настоящем телефоне. Подробно — [code/README.md](code/README.md).
6. **Спека в Claude Doc** («Огневой рубеж: техническая реализация мобильной версии») — общий обзор. Источник правды по деталям — эти файлы.

## Ветки

```
docs/
├── README.md                ← эта карта
├── QUESTIONS.md             ← вопросы, ответы, журнал решений, отложенное
├── ASSETS.md                ← что принести: фото, звуки, рисунки
├── design/
│   ├── TOKENS.md            ← цвета, шрифты, размеры, звук и вибрация
│   ├── briefs/              ← задание на каждый экран для дизайнера-Claude
│   ├── CANVAS-FIXES.md      ← логические правки к готовым холстам
│   └── DESIGN-CURRENT.md    ← как приложение выглядит сейчас (до рестайла) + screens/
├── logic/
│   ├── FORMULAS.md          ← все игровые формулы, константы, округления
│   ├── COURSE.md            ← курс, оценка, звания, учебник
│   ├── CHECK-RESULT.md      ← проверка расчёта АВТО / САМ
│   └── SCOPES.md            ← каталог прицелов (план)
├── code/
│   ├── README.md            ← порядок работы, матрица устройств, шаблон спеки
│   ├── specs/               ← спека на каждый модуль
│   └── BACKLOG.md           ← что поменять в коде по каждому решению
└── research/
    └── SNIPER-PROGRAMS.md   ← реальные учебные программы и нормативы
```
