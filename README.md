# Огневой рубеж — мобильная версия

Симулятор подготовки к стрельбе на дистанциях до 1000 м: курс из 13 упражнений, свободная игра, журнал, учебник. Отдельный проект, к Carebox не относится.

- Техническая реализация (источник решений): https://claude.ai/artifact/M7u2xxQNDfYdEnNFM2JvHt
- Дизайн-система «Хаб расчёта» (источник вида и поведения): https://claude.ai/artifact/3bVMwcYNSDQEVPVER1VbEE
- Веб-альфа 3 и мобильная пре-альфа — источник ядра, перенесено в `src/core` и `src/sim`.
- Документация, решения и порядок работы — [docs/README.md](docs/README.md); что сделано и что дальше — [docs/code/BACKLOG.md](docs/code/BACKLOG.md).

## Стек

Angular 21 (zoneless, standalone) + Ionic 8 + Capacitor 8, js-ballistics 3.1.0. Сцена в стекле — Canvas 2D из фото-слоёв (A9.1); PixiJS 8 в зависимостях, в коде пока не используется (кандидат для миража, A9.2).

## Слои

```
src/core   чистый TS: баллистика, карточка ДОПЕ, сценарий и ветер, выстрел, игровые формулы, оценка, проверка расчёта, подвижная цель
src/sim    без DOM: пульс, покачивание и дыхание, спуск, затвор, прицелы и барабаны, сессия прицела, курс, серия, блокнот, разбор выстрела, свободная игра
src/app    Angular/Ionic: экраны, хранилище (Preferences), звук и вибрация, сцена и рендер прицела
e2e        пользовательские сценарии Playwright, портрет 390×844, два телефона
```

## Команды

```
npm start              dev-сервер
npm run start:lan      dev-сервер в локальной сети — для настоящего телефона
npm run test:unit      юнит-тесты core, sim, theme и моделей app (Node, vitest)
npm run test:e2e       пользовательские сценарии на dev-сервере (Playwright: mobile-chromium и mobile-webkit)
npm run test:e2e:build полный прогон на собранном приложении (порт 4320) — перед слиянием
npm run build          сборка
npm run docs:dope      печать карточек ДОПЕ для документации
```

Node 22.22+; установка зависимостей — с `legacy-peer-deps` (прописано в `.npmrc`, обход ошибки npm в разборе peer-зависимостей).
